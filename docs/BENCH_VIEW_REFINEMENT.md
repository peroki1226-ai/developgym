# 水平ベンチ・近い視点・胸の収縮強調（ユーザー指定 / TASK-040）

## 変更

- 通常のベンチプレスの台を、床に対して水平なワールド座標へ固定。台・裏板・縁・下の横フレームの向きは人体やバーの動きに依存しません。前後の支えを同じ高さにし、通常ベンチの斜めの調整材を外しました。水平面の四隅と固定状態を全４１姿勢で検証します。インクラインベンチは引き続き約３０度です。
- 平面表示の台は、立体と同じ座標・軸の面を投影するように変更。従来は軸を無視した縦長の画面上の四角形だったため、台の向きが正しく伝わりませんでした。
- 全体のカメラの余白を縮小。収容距離への倍率を１．１２→１．０３５にし、カメラを約７．６％近づけています。人体・器具・全視点の画面内収容を確認します。以前の非表示の筋繊維バッファや未使用領域は、実際に見える範囲の検査から除外し、表示中の筋繊維の実座標は別途検証します。
- ディップスとペックフライの胸の変形だけを１．３５倍に強調。筋腹の膨らみと短縮方向の変化を増し、模型上の金色区間の終点での長さは従来の約７４％へ。下の胸の補助図も同じ強調率に合わせています。筋肉以外の頂点・握りの基準・器具の軌道を変えず、他種目へ強調を波及させません。

変形と金色区間は教育用の強調で、実測筋長・筋力・筋電図ではありません。動作範囲を深くしたり、肩や肘を無理に動かしたりする変更ではありません。既存の再生時計、低速、手動操作、停止/再開、記録保存、言語切替を使います。

## プレビュー

main同期後、古いプレビューを止めて実行してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja` または `?lang=en`。凍結中の index.html は対象外です。

- 胸のコース→ベンチプレス→横から、上から、再生/手動操作。台と床の平行と固定状態を確認。
- 詳細操作→平面表示でも、台が水平な面として表示されることを確認。
- ディップス/ペックフライ→筋肉の収縮を拡大→伸びた姿勢/縮んだ姿勢→低速再生。胸の筋腹・金色区間・方向矢印の変化を確認。
- 全体を近づけた状態で、手足・器具の見切れと元の記録/入力保持を確認。

実iPhoneでの見た目・速度の受入は別途です。今回の依頼のみを実施し、新規EASビルド・TestFlight提出/配布は行いません。
