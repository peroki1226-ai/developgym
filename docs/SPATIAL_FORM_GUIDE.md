# TASK-029 三方向から確認する立体フォームガイド

2026-11-07（日本時間） / ユーザー差戻し・形状の再制作中

**最新状態**: 「器具形状が実物と違う」というユーザー指摘を受領。以下は前回の汎用模型の実装履歴であり、実物一致の証拠ではない。TASK-029をIN PROGRESSへ戻した。[監査と再制作条件](MACHINE_REFERENCE_AUDIT.md)と、後続の[ハンマーストレングス優先・スミス修正](HAMMER_SMITH_GUIDE.md)を参照。

## 今回の変更

「器具が簡易で動作を想像できない」「人と器具の配置がおかしい」「負荷部位が見えない」「一方向では分からない」という指摘に対応する。全24種の人体と器具を、Three.jsの三次元メッシュとして生成する。写真や外部模型の取得は不要。

| 操作 | 確認すること |
| --- | --- |
| 前から / 横から / 後ろから | 同じ動作位置を保ったまま、人体・座面・握り・足台の配置を見る |
| ①構える / ②動かす / ③戻す | 開始・終点・戻り途中の姿勢で停止して確認する。再生でその位置から動かす |
| 手の位置 / 足・膝 | 接点の白い目印と、腕・脚に寄った表示で置き方を確認する |
| 負荷部位 | 主に使う筋肉へ寄り、見えやすい方向と器具の透過表示へ切り替える |
| 器具を透かす | 背面のパッドやフレームで隠れた身体を見る。後ろの視点は透過から始まる |
| 低速 / さらに低速 | 既存の半速・四分の一速、41段階の手動操作で動きを追う |
| 図解で見る | 従来のSVG図解・軌道・関節拡大で確認する |

人体は連続した胴体・腕脚の面、頭・首・骨盤・指・靴を持つ。器具は座面、背/胸/腿パッド、フレーム、重りとピン、支柱、レール、プーリー/ケーブル、握り、足台を種目ごとに構成した。バーと顔の間隔、補助懸垂の固定握りと可動膝台、固定レールと可動スレッド、背筋ベンチの固定股関節パッドを個別に扱う。

着色は主に使う筋肉の模式的な位置を示す。胸・背中・肩・腕・脚を別々の面に着色し、筋繊維の模式パネル、短縮・伸長・姿勢保持の説明は既存のものを維持する。赤い強さは実測負荷や筋活動量を表さない。

## 実装と運用

- `mobile/src/domain/training3d.ts`: 純粋な三次元座標、関節、器具、接点、視点。
- `mobile/src/three/trainingScene.ts`: メッシュ、光源、筋肉の頂点色、接点、カメラの自動収まり。メッシュを再利用し、破棄時にGPUリソースを解放。
- `Motion3DView.native.tsx`: Expo GLで描画。`Motion3DView.web.tsx`は同じシーンをWebGLで描画し、ローカル検証に使用。
- `ExerciseDiagram.tsx`: 視点・接点・姿勢操作。初期状態は停止。既存の動きを減らす設定、非表示/背景停止と一つの再生クロックを維持。
- GL初期化失敗・コンテキスト喪失・8秒の読み込みタイムアウト時は、動作位置を保持してSVGへ切り替える。立体表示の再選択で再試行できる。
- 保存スキーマ、検索、記録、言語、EAS設定、凍結中のルートWebには変更しない。

追加依存はExpo SDK対応の`expo-gl ~58.0.3`と、WebGL1も扱う`three 0.160.x`。**既存の署名済みアプリへのJavaScript差分だけではGLを追加できないため、新しい署名付きネイティブビルドが必要。** GLがない既存バイナリはSVGを使用する。

この作業ではTestFlightのビルド・提出・招待、および新規Ad Hocクラウドビルドを実行しない。配布の明示指示後、登録済みiPhone向けpreviewビルドで検証する。

## 検証と受入の限界

- Jest: 27スイート / 334テスト合格（既存304、新規30）。全24種×21位置の有限座標・器具識別子・接点、固定支点/レール、カメラ収まり、描画再利用・破棄、日英UIと失敗時の姿勢保持を検証。
- TypeScript・`release:check`合格。iOS/Android Hermes・Webのローカル書き出し成功。
- 実WebGL: 320/390px×日英×24種=96状態、各3姿勢×3視点=864姿勢視点。24種の筋肉の可視着色ピクセル、言語混入/横はみ出し/実行エラー0、低速差、動きを減らす設定、コンテキスト喪失と再試行時の姿勢保持を確認。三方向一覧・接点/筋肉表示・低速連続キャプチャGIF・検証JSONをレビュー資料へ添付。

模型は汎用器具の学習用モデルで、特定メーカーのCAD、精密解剖、実測筋活動、個人に合わせた可動域を再現するものではない。視点は三つのプリセットで、自由回転ではない。**iPhoneのGL互換性、滑らかさ、発熱、VoiceOver、実機の身体/器具との整合は未確認。** ブラウザ画像は同じネイティブUIをExpo Webで描いたもので、実機録画やインストール済みアプリの証拠ではない。

受入では「使い方を想像できるか」を、前後の画像だけでなく実際の三方向切替で確認すること。自動テスト合格をユーザーの分かりやすさの受入完了として扱わない。
