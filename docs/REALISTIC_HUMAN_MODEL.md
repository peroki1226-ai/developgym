# TASK-031 自然な人体と、関節に沿う筋収縮

2026-11-09（日本時間） / 見た目の再受入待ち

ユーザー指定は「自然なもっとリアルな人体」「筋肉の収縮も人体にある筋肉のように自然に」。従来の球・円柱の人体と、別オブジェクトの筋肉面を廃止し、顔・耳・指・関節まで連続する人体メッシュへ置き換えた。全24種目で同じ人体と骨格を使用する。

## 変更した表示

- 著作権表示を確認したMakeHumanのCC0グラフィック資産から、成人の人体形状・骨格・スキンウェイトを同梱。13,905頂点、27,720三角形、22骨格コントロール。起動時の外部模型ダウンロードは不要。
- 腕・脚を元の模式図の長さに引き伸ばさず、人体に合わせた一定の骨長に変換。肩の関節位置を首より下・体側に置き、肘・膝の形をスキンウェイトでつなぐ。
- 指を握る形へ事前ポーズし、手首から手の長さを含めて握り位置を合わせる。足裏は既存の接地面に合わせる。
- 胸のプレスは同じ支点を回る一定半径の軌道。スミスは人体の可動範囲に合わせたグリップ幅・鉛直ストローク。懸垂・ディップは握り位置を固定し、体側が移動する。
- 筋肉の着色は人体表面へ統合。対象だけ赤茶、他の人体・器具は灰色。細い筋繊維模様を控えめに入れる。
- 関節をまたぐ模式的な筋の経路長から短縮量を求め、筋腹の厚みと軸方向の形を変える。端部への変形は滑らかに減衰。色表示を消しても人体の形は同じ。
- 静止した姿勢で筋肉だけ脈打つ処理はない。戻し動作は同じ形を逆方向にたどる。二頭筋・三頭筋は拮抗する経路を持つ。
- 筋肉の拡大カメラは動作全体の範囲を固定して使用。姿勢ごとに勝手にズームせず、縮む・伸びる形を比較しやすくした。

三方向視点、低速/四分の一速、片道再生・終点停止、動きを減らす設定、手動コマ送り、図解への切替、言語切替、記録保存の操作は維持する。保存キーやスキーマは変更しない。

## 検証の範囲と残り

人体比率・連続変形・色の独立性・固定姿勢・拮抗筋・接地・カメラ・解放を自動テストする。Chromium/SwiftShaderの実WebGLで日英・320/390幅・24種目・三方向・低速停止を実行し、実描画の前後比較とコマ送り動画を取得する。iOS/AndroidのローカルHermes書き出しも確認する。最終件数はDEV_STATEの当日ログ参照。

これは学習用の人体表示で、個人の筋束/腱の実測、羽状角、筋力、筋活動量の計算ではない。色領域の一部は短パン越しに投影する。器具は既存の汎用模型を接点に合わせて調整しており、ハンマーストレングスの実機形状一致を完了したことにはしない（TASK-029）。

見た目の受入、実機iPhoneのGL描画・発熱・速度・VoiceOverは別途未確認。テスト合格をユーザーの見た目の受入としない。TestFlight、新規EASジョブ、署名ビルド、iPhoneへの配布は実行しない。
