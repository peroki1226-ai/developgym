- 作成日：2026年11月3日（日本時間）
- 送信元：Codex（実装担当）

- 状態：IN REVIEW（実装・自動検証済み、受入レビュー待ち）

## ユーザーの依頼

> レイアウトとか変える前に初心者に向けて視覚的に模型みたいなのでそのマシンの使い方について表してたのも入れて

現在のシンプルで高級感のあるレイアウトに、以前の「人物とマシンの模型のような図で使い方を理解できる説明」を組み込む要望です。初心者が文章だけに頼らず、姿勢と動く方向を見て理解できることを重視します。

## 対応内容

| 項目 | 実装内容 |
|---|---|
| 見つけやすい入口 | ホームに図付きガイド入口、メニューに12種目の選択、ジムの設備一覧に対応マシンの使い方ボタンを追加 |
| 視覚的な使い方 | 既存12種目のSVG図解を再利用。人物・マシン・動作の矢印を表示し、凡例を追加 |
| 初心者向けの順序 | 初心者モードで開き、図解を先に表示。座席/器具の調整、動作手順、既存の注意点を確認できる構成 |
| 元の機能の維持 | 本格モード、機種変更、重量/回数/セットの記録、5タブ、検索・お気に入り・食事・投稿・日英切替を維持 |
| 元の画面への復帰 | 全画面モーダルで元の画面を保持。固定の戻る操作と、検索語・メニュー検索・入力途中のフォームの保持 |
| 通信への依存 | 図解は同梱SVG。ガイド表示に外部サーバーや一時トンネルを使用しない |

人物・マシン・動作矢印は、既存のSVG図解を使用しています。

## 検証結果

- 全18スイート / 129テスト合格（既存124件＋追加5件）。
- TypeScript型チェック、release:check合格。
- iOS/AndroidのHermesバンドル生成成功。
- 全12種目を日英の初心者モードで直接開けることを確認。
- 選択したマシン名での記録、対応するジム設備からの表示、元画面の検索/入力保持、通信遮断下での表示を確認。
- Chromiumの320/390px・日英・3機種で計12表示を確認。図解の初期表示、固定の戻るボタン、言語混在/横はみ出し/実行エラー0を確認。

## レビューをお願いしたい点

1. 初心者がホーム・メニュー・ジム設備から図解へ迷わず進めるか。
2. 人物の姿勢、マシン、動作方向と、座席調整・動作手順の対応が分かりやすいか。
3. シンプルで上質なレイアウトを保ち、図解が十分な大きさで表示されるか。
4. ガイドを閉じたときに元の検索条件・入力が保持され、記録が正しい種目へ保存されるか。
5. 実機iPhoneでノッチ/ホームバー、文字拡大、VoiceOver、モーダルの開閉と戻る操作を確認。
