# 英語モードの再監査（2026-11-08、日本時間）

## 表示の基準

英語を選んだ時は、画面見出しだけでなく、ボタン、入力案内、器具・ブランド名、筋肉名、初心者/本格ガイド、動作の説明、警告、エラー、読み込み表示も英語にする。画面を開いたままの切替と再起動後の復元を対象にする。

利用者が入力したレビュー・メモ・食事名の保存原文は保全する。任意の文章を自動翻訳する通信サービスは今回追加していない。提供データとアプリ自身の文言について言語分離を監査する。

## 修正

- 検索状態復元中の「読み込み中…」に英訳がなく、そのまま日本語を返す経路を修正。
- 言語の復元前は文字を出さずスピナーで待つ。保存済み英語設定を読む前に、日本語の読み込み文が一瞬出ることを防ぐ。
- 保存データを読めない画面にも言語切替を追加。英語で復旧操作できるようにし、失敗したデータは上書きしない。
- アプリ版プレビューのブラウザー言語情報と、各画面の読み上げ言語を選択言語に同期。
- プレビュー入口/未起動/ソース更新時の案内も、保存済みアプリ言語に従う。古い表示を拒否した場合に日本語だけのエラー画面へ戻さない。
- `npm run i18n:check`で辞書1,278項目の日英対、文字種、差し込み値、画面の固定文言585件を検査する。`release:check`と`preview:app`の生成前にも実行し、新しい固定文言の翻訳漏れを失敗として検出する。

既存の言語状態/保存キー/データ形式、ジム検索、筋肉模型の形、トレーニング記録は変更していない。未確認の動的な利用者入力を、空欄や無関係な英語へ置き換えて監査を通す処理は追加しない。

## 動作確認

実際のReact Native画面をExpo Webで動かし、iPhone相当幅のChromiumで83状態を検査した。

- 探索の検索条件、地図、メニュー、お気に入り、マイページ。
- ジム詳細の設備/料金案内/レビュー、全都道府県/ブランド選択。
- 家トレ、食事、トレーニング。
- 全24種目×初心者/本格ガイド、筋肉/動作の展開詳細。
- 開いている画面での日→英→日の切替、重量と模型の姿勢の保持。
- 再読み込み後も英語を復元。入口/古いプレビュー案内も英語。

提供文言・表示中のラベル・入力案内・読み上げラベルで他言語の混入なし、ブラウザー実行エラーなし。低速動作/3Dの実機品質の受入とは別。OSの写真選択画面など、アプリ外の画面は端末側の言語設定に従う。

## Antigravityで反映する手順

1. 作業差分を保全して最新mainへ同期。
2. 以前のアプリ版プレビューサーバーを停止。
3. `mobile/`で`npm run preview:app`を再実行。
4. `http://localhost:3000/app-preview/`の**アプリ本体**のEnglishボタンを押す。固定日本語の説明を重ねた別アーティファクトを、英語化の判定対象画面として使わない。
5. 英語の探索画面と筋肉模型のガイドを開き、生成元情報・画面を一緒に記録して利用者へ提示。

この環境での実描画と、Antigravity側の反映、iPhoneの更新確認を区別する。TestFlight/EASの新規ビルドや配布は実行しない。
