# 人体の形・関節・質感の修正（ユーザー指定 / TASK-037）

「まだ模型の人体が実際の人間の体と違う」という指摘への対応です。人体の表示を対象とし、器具の形やワークフロー、保存形式を増やしません。TASK-036までの受入と、TestFlight/配布を保留する方針を維持します。

## 形状から修正したところ

同じピン留めCC0人体を `natural-athletic-adult-v3` として再生成しました。肩の球状の膨らみ、上腕・腿・ふくらはぎの上乗せ量、胸下部の丸みを抑え、上胸部から脇へつながる厚みを配分しています。前の体型が存在しないという意味ではなく、フォームを読みやすい別の成人の教材体型へ整えたものです。

同一の元データ・23素材・骨格制御・13,905頂点・27,720三角形を使用します。新しい形状から法線、衣服の追従、筋肉の領域を再生成し、胸だけの将来のマスク更新は新しい形状を変えないよう基準値も更新しました。色だけの変更ではありません。

## 曲げても厚みを保つ関節

従来の線形ブレンドでは、隣接骨の回転を平均する際に肩・肘・手首が細くつぶれやすい状態でした。回転と移動をデュアルクォータニオンで補間し、器具へ合わせる伸縮分は別の補正として保持します。単一骨の頂点は従来と同じ変換へ正確に追従し、握り・足・座席の目標は変更しません。

骨が長くなると腕や足まで太くする処理も外し、断面を人体全体の基準スケールにそろえました。約68%の頂点は単一骨へ固定されているため、そこには直接変換を使用します。オブジェクト・追加の再生時計・人体メッシュを増やしません。

## 表面と顔

強いプラスチック感を抑えた、つやの少ない肌色に変更。眼球の位置・形状を維持したまま、白目・虹彩・瞳を別の頂点色で表現します。筋肉の赤茶色はその上に重ね、着色を消すと肌と目の色へ戻ります。肌の写真や実行時の外部テクスチャは使いません。

特定の人物の同一性や写真と同じ外観、医学的な筋長・筋力の計測を再現するものではありません。

## 動くフォームガイドとの関係

全26種目の三方向・拡大・再生・低速・停止・手動バー・筋肉の短縮/伸張を引き継ぎます。種目ID、ジム情報、人体と器具の目標接点、運動記録の保存キーは変更しません。実機の描画速度・発熱と見た目の受入は、デスクトップ検証とは別に確認が必要です。

## 再生成

```bash
python mobile/scripts/build-human-model.py --source-root /path/to/pinned/makehuman --output /tmp/natural-human-rebuilt.json
python mobile/scripts/human_pectoral_masks.py --check
```

元データのコミットは `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`。AGPLのアプリケーションコードは転用せず、CC0の素材だけを使用しています。別ファイルへの再生成結果とのバイト一致も確認します。
