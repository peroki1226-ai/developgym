# 詳しい動作ガイド・ゆっくりモード（TASK-025）

2026-11-06（日本時間）。全24種類の模型を、動かす部位と支える部位、関節の曲がり方、往復の手順を確認できる表示へ更新しました。

## 見方・操作

- **① 固定・支える位置 / ② 動かす位置**：模型上の番号と説明を対応させます。固定位置は種目に応じて骨盤・肘・膝・足・グリップ等を示します。
- **関節の拡大**：現在の模型と同じ座標から肘・膝・肩・股関節・足首・上体の動きを拡大表示。開始姿勢の薄い線と現在の曲がり方を比較できます。表示は折りたためます。
- **局面ごとの説明**：構え、力を入れる動作、切り返し、戻す動作の説明を24種類に用意しました。戻す局面では矢印も反転し、軌道の線は現在位置まで伸縮します。
- **通常 / ゆっくり / 超ゆっくり**：速度は1倍・0.5倍・0.25倍。1往復は約5.1秒・10.2秒・20.4秒の学習用テンポです。速度選択は模型の上に配置し、同じガイド内で別の種目へ切り替えても選択速度を保持します。
- **41段階のコマ送り**：模型の下の左右ボタンで、動作位置を5%ずつ確認できます。開始→動作→切り返し→戻す→開始の順に進み、操作すると一時停止します。描画そのものは連続アニメーションで、41段階は姿勢を検査する位置です。
- **位置指定と再開**：バーをなぞって途中の姿勢を確認できます。停止位置と動く方向を保って再生し、速度変更でも姿勢を飛ばしません。開始/終了姿勢ボタンも維持します。

## 動作の細部

主模型と拡大図は別々の動きではなく、同じ関節座標を使います。角度を変えずに拡大し、種目ごとの固定位置も実際のモデルの位置に対応させています。

アブドミナルクランチは骨盤と下部の位置を固定し、背中の複数の部分を段階的に丸める表示に変更しました。股関節から上体全体を動かすバックエクステンションとは異なる動きです。

説明文の長さで模型が上下に動かないよう、各局面の説明高さを測って枠を確保します。日本語/英語、画面幅、文字サイズの変更に合わせて測り直します。

## 実装

- `domain/motionTeaching.ts`：24種類の固定/動作位置、関節、局面別説明、角度を保つ拡大計算。
- `MotionJointDetail.tsx` / `MotionCue.tsx`：関節拡大と位置が安定する説明欄。
- `ExerciseMotionScene.tsx`：番号、現在の軌道、往復で反転する接線方向の矢印、背中の屈曲表示。
- `exerciseMotion.ts` / `useExerciseMotion.ts`：3段階速度、41段階の往復操作、補間の逆算による位置指定→再生の連続性。
- 日英辞書、`ExerciseDiagram.tsx`と関連テストを更新。追加依存・権限・保存スキーマ・EAS設定の変更はありません。

動きを減らす設定では自動再生せず、手動操作・拡大図を利用できます。背景、非アクティブ画面、破棄時のループ停止も維持。小さい一覧用図解は静止表示のままです。
