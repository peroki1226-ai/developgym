# シンプルで上質なネイティブレイアウト（TASK-020）

ユーザーの「機能はそのままで、もっとシンプルで高級感のあるレイアウト」に対応。mobile/の画面表示を変更しました。

## デザインと配置

- 白と淡いグレーを基調に、濃紺の文字と落ち着いた青を使用。塗りつぶしは検索・結果表示・ルートなどの主操作に限定し、選択項目は淡い背景で示します。
- ヘッダーをロゴと小さな日英切替へ統一。旗の大きなボタンや重複するブランド表記を減らし、細い区切り線と文字の大きさで階層を示します。
- ホームは写真を小さくし、検索と候補を上へ移動。記録ツール・器具検索・おすすめ・比較への入口は候補一覧の後にまとめます。別タブの共通ヘッダーからも記録ツールに移れます。
- 種目・部位・ダンベル条件は「検索条件を調整」、店舗の細かな設備・不足器具・投稿は各店舗の「設備・投稿」から開きます。
- 折りたたみは子コンポーネントを破棄せず、非表示と読み上げ対象外を切り替えます。入力途中の設備修正や投稿フォームを維持します。言語切替・ボタン・記録ツールの操作領域は最低48ptを確保します。

## 維持した機能

5タブ、検索・メニューマッチ計算・重量フィルター、地図・比較・器具検索・条件提案、お気に入り、ジム/家トレ記録、体重/食事/PFC、設備修正・写真・レビュー、日英切替と端末保存を維持。ドメイン計算・状態・保存スキーマ・店舗データ・権限・EAS設定は変更していません。旧Webプロトタイプのindex.htmlも変更対象外です。

## 検証と配布の境界

- 17 suites / 124 tests、型チェック、release:check成功。既存の言語・検索・投稿テストは、新しい折りたたみを開く操作へ更新し、設備フォームの入力保持も確認しました。
- iOS/AndroidのHermesバンドルと、ネイティブUIをブラウザーで検証するExpo Webエクスポートを生成。
- Chromiumの320/390px・日英・5タブ=20状態で、言語混在・横はみ出し・実行エラー0。390×844では検索と最初の候補がタブバーより上に表示されます。検索入力のDOM/フォーカス維持と、重量条件の折りたたみ後の保持を確認しました。
- 実機iPhone、Dynamic Type/VoiceOver、署名付き新版の更新は未確認です。画像はブラウザーで描画した同じネイティブUIのレビュー用で、実機スクリーンショットではありません。
- 提出済みBuild 3は今回の変更前のソースです。IOS_RELEASE_STATUS.jsonの対象を改変・再提出せず、受入後に新しい署名付きビルドで反映します。OTA無効の設定を維持しているため、既存アプリへ今回の見た目が自動反映されることはありません。
