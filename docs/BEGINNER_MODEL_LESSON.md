# 初心者向け：動く模型で覚えるマシンの使い方（TASK-032）

## 画面で確認する順番

探索の「模型でマシンの使い方を見る」、メニューの種目別「使い方」、ジム詳細の器具別「使い方」から、同じネイティブガイドを開きます。初心者モードの中心表示は、これまで制作した人体・器具の動く三次元模型です。

| 段階 | 模型の表示 | 操作 |
| --- | --- | --- |
| 姿勢 | 全体と種目別の座席・姿勢の説明 | 座る位置と体の支え方を確認 |
| 手 | 握り位置へ拡大 | グリップ、親指、手首の位置を確認 |
| 足 | 足の位置へ拡大 | 足台・パッド・膝の位置を確認 |
| 動作 | 横から全体を見る | 動かす局面と戻す局面をそれぞれ低速で再生 |

「次へ」で順番に進み、上部の4項目で戻ることもできます。段階を切り替えると開始姿勢で停止するため、再生中でも位置を落ち着いて確認できます。エクステンション、カール、内転/外転、バックエクステンション、補助懸垂/ディップは、足・パッドの説明を器具に合わせています。

動作画面には「準備 → 動かす → ピーク → 戻す」の現在局面を重ねて表示し、種目ごとの初心者手順と呼吸も実際の再生位置へ同期します。準備段階には男女別の開始重量目安とNG注意点を表示します。

動作は既存の四分の一速・片道再生を利用し、終点で停止します。一時停止、開始姿勢、終了姿勢にも対応。端末の「動きを減らす」が有効なときは再生を抑止し、手動で姿勢を確認します。

## これまでの模型・機能との関係

新たな簡易模型への置換ではありません。既存の人体メッシュ、写真型の胸/脚器具、筋肉の着色・変形・矢印、24種目/25機構、握り接点をそのまま使用します。GLが利用できない場合の既存SVGフォールバックも維持します。

三方向の視点、筋肉の詳しい観察、速度変更、コマ送り、2D/3D切替は「視点・再生の詳しい操作」から開けます。本格モードにも従来の操作を維持しています。模型を二重に起動せず、同じビューへ姿勢・拡大箇所を渡します。

重量・回数・セットの入力、トレーニング記録、検索条件、レッグプレスの座席移動/四十五度切替は維持。保存キー・スキーマ・権限・依存パッケージは変更していません。日英両方の同じ導線で利用できます。

## Antigravityの再表示手順

1. 最新mainを同期する。
2. `cd mobile` で `npm run preview:app -- --port 3000` を実行する。
3. `/app-preview/?lang=ja` または `/app-preview/?lang=en` を開く。
4. 探索画面の「模型でマシンの使い方を見る」から、姿勢 → 手 → 足 → 動作を確認する。
5. 胸・脚の機種、上級操作への往復、ガイドを閉じた後の検索状態、記録入力の保持を確認する。

ルートの旧 `index.html` や古い生成済みプレビューでは変更を確認できません。プレビューはネイティブと同じ `mobile/App.tsx` から再生成します。
