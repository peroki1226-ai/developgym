# ベンチの上方視点・筋肉模型と動く収縮ガイド（ユーザー指定 / TASK-039）

## 画面で変えたこと

- ベンチプレス、インクラインベンチ、インクラインダンベル、インクラインスミスに「上から」を追加。真上の特異点を避けた斜め上方から、左右の握り・肘・胸とバーの位置を確認できます。正面・横・背面も保持しています。
- 初心者の視点ボタンを模型の前へ配置。上方視点を選んでから再生・姿勢切替しても、勝手に正面へ戻りません。
- 全身の筋肉模型を `muscular-teaching-adult-v4` へ。肩・肘・膝の端を太らせず、筋腹の厚みと上胸部の立体感を強めています。同じCC0素材・１３９０５頂点・２７７２０三角形・２２骨を使用し、関節基準点と握りの基準は前版と完全一致です。
- 胸の８種目では、模型の胸に筋繊維の扇形を表示。薄い線は繊維方向、金色の区間は筋繊維の一部分の短縮/伸張の模式表現です。両端の目印が近づく/離れる様子と白い方向矢印が、手動バー・再生・戻す局面に同期します。
- 模型上へ「狙う部位」と「縮みながら力を出す／伸びながら支える」を表示。赤い領域は大胸筋全体または上胸部の強調です。色の濃さから負荷・筋活動を数値化しません。
- 模型直前の「筋肉の収縮を拡大」で胸が画面に大きく入り、器具を半透明にして遮蔽を減らします。模型と同じ姿勢を保って全身表示へ戻れます。
- 「伸びた姿勢を見る」「縮んだ姿勢を見る」で両端を直接比較。胸ディップスも正しい往復位置へ移動します。下の補助図も単独の紡錘形から、胸骨を挟んだ左右の扇形へ変更しました。

## 模型と模式表現の区別

筋繊維の線は、元の胸の前面にある実メッシュ三角形を一度だけサンプリングし、同じ頂点の変形へ重心座標で追従します。腹部・背中・衣服へ任意の線を浮かせる方式ではありません。

皮膚の線の長さは、そのまま筋繊維の実長にはできません。肩の動作で皮膚が伸びても、その下の筋肉は短縮するためです。向きを示す扇形を残し、その内側の金色の区間を弧長で短く/長くして、縮む・伸びるの意味を読み取れるようにしています。これは教育用の強調であり、生理学的な長さ・筋力・筋電図の測定ではありません。筋腹の変形は従来の定性的な筋経路モデルに従います。肩や腕も運動を助け、胸の一部分だけを完全に分離するとは案内しません。

筋繊維と矢印は筋着色OFF・他部位の種目で非表示になり、表示バッファと目印を再利用してアンマウント時に破棄します。新しい再生時計・通信資材・依存はありません。既存の低速、停止/続きから再開、１往復終了、動きを減らす設定、手足接点、記録保存は維持します。平面表示への自動フォールバック時に上方視点を表示することはありません。

## 確認手順

mainを同期し、古いプレビューを止めて以下を実行してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja` または `?lang=en` を使用し、凍結中の `index.html` は使いません。

1. 探索→「胸の種目を模型で学ぶ」→「胸の種目から選ぶ」→ベンチプレス。
2. 模型の前で「上から」→「この模型の正しい動きを見る」。視点を保持してバーが動くことを確認。
3. 「筋肉の収縮を拡大」→「伸びた姿勢」「縮んだ姿勢」。金色の区間と目印・胸の厚み・狙う部位を比較。
4. 指でバーを前半/後半へ動かし、後半で方向矢印と短縮/伸張の表示が反転することを確認。四分の一速で再生、停止/続きから再開、１往復終了も確認。
5. ８種目・日本語/英語で狙いが切り替わり、全身へ戻しても姿勢を保持し、記録・元画面へ戻る機能が使えることを確認。

実iPhoneの見た目・速度・受入は別途です。今回のユーザー指定改善のみを実施し、新規EAS署名ビルド・TestFlight提出/配布は行いません。
