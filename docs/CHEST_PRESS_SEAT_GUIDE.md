# TASK-049: チェストプレスの座面高と胸の狙い

2026-11-16。ユーザー指定の「椅子の高さによって効かせる胸の部位が変わることも加えて」に対応。TASK-048は2594776で受入済み。今回の追加解説のみを実施する。

## 追加内容

チェストプレスの動く模型の直下に「座面の高さで胸の狙いはどう変わる？」という折りたたみ解説を追加。初心者/本格のどちらでも利用できる。基本の高さから、少し低め/少し高めの3段階を比較できる。

| 設定 | 胸に対するグリップの位置 | 説明する負荷の変化 |
| --- | --- | --- |
| 基本の高さ | 胸中央付近 | 初心者の基本。胸全体で押し、肘は肩より少し低く保つ |
| 少し低め | 上部寄り | 胸上部や肩前面の関与が増える場合がある |
| 少し高め | 中〜下部寄り | その周辺への負荷の配分が変わる場合がある |

固定したグリップの青い点線に対して座面・体幹・肩の位置が上下する比較図で、座面とグリップの相対関係を示す。胸の着色で部位の目安も示す。

「座面だけで胸上部/下部を分離できる」と断定せず、機種の軌道・背もたれ角度・体格にも依存すると記載。肘が肩より高くなるほど下げないこと、足が浮くほど上げないこと、背中/臀部/足裏の支持、座面ロック、軽い設定での確認を説明する。既存の座面セットアップ本文にも同じ原則を反映した。

比較図は説明用であり、実際の負荷量を算出しない。上の3D模型は基本の高さの見本であることを明示。比較の選択は3D模型の座面・骨格・筋肉着色・軌道・再生状態を変更しない。新規アニメーション、時計、ストレージ、依存追加なし。
