# 写真を参考にした全身の筋肉模型（TASK-034）

「まだ模型が不自然」「写真のようにもっと人体へ近づけたい」というユーザーの指摘を受け、着色だけでなく人体そのものを修正しました。胸の位置修正（TASK-033/d303fdd）の受入は6022575で保全し、今回の全身修正をTASK-034としてレビュー依頼します。初心者ガイドも引き継いでいます。

## 形状と変形

- 元のCC0人体に、肩・上腕・背中・胸・腹部・太もも・ふくらはぎ・首の作者制作の形状データを適用。関節の両端や骨格ヘルパーを動かさず、筋腹の厚みを制限付きで増やしています。
- 胸の下側の過度な丸みを抑え、上胸郭へ厚みを配分。腹直筋の左右の筋腹と浅い腱の溝も、実際の頂点形状へ反映。色を消しても形状が残ります。
- 曲がった元の背骨を骨ごとに独立回転していた処理を、胴体の断面を保ちながら姿勢へ沿わせる処理へ変更。2点の直線背骨には線形補間を使い、胸が下へ引かれたり、肩と胸郭の高さがずれたりする変形を修正しています。
- 衣服へ近傍の人体の骨格重みを移し、肌からの余裕を設けて、腰・太ももの動きへ追従させています。
- 実際の凹部から弱い陰影を焼き込み、光の当て方と材質も調整。筋肉の輪郭を線で貼り付ける方式ではありません。

## 動くアプリへの反映

同じ人体データを全24種目で使います。器具や人体の接点目標、種目ID、記録、言語、初心者の4段階、筋肉の着色、低速・片道停止・コマ送り、三方向の視点を維持しています。保存形式・権限・依存パッケージは追加していません。

元と同じ13,905頂点・27,720三角形・人体メッシュ1個を維持。新しい筋肉メッシュや描画ループ、実行時の外部テクスチャ・モデル取得は追加していません。写真は筋肉の量感とつながりの参考であり、写真の人物の同一性や実測寸法の再現ではありません。教材としての模式的な収縮で、医学的な筋束や筋活動量の計測でもありません。

## 出典と再生成

MakeHumanのCC0グラフィック素材を既存と同じコミット `a8bc2d54ff0ac92e78ff71431b1023eda42bf482` へ固定。追加の形状素材を含む23ファイルのハッシュを生成データへ記録しています。アプリケーションコードの転用はありません。独自の筋腹・腹部修正、衣服追従、陰影計算はGymFinderの変換処理です。

```sh
python mobile/scripts/build-human-model.py --source-root /path/to/pinned/makehuman
# ソースを変更せず、再生成結果を比較する場合
python mobile/scripts/build-human-model.py --source-root /path/to/pinned/makehuman --output /tmp/human-rebuilt.json
python mobile/scripts/human_pectoral_masks.py --check
```

今回の全身修正では、以前の「胸のマスクだけの更新」と異なり、元の形状・法線・骨格基準・衣服重み・領域も意図的に再生成しています。対応する回帰テストの基準値は新しい人体へ更新しています。来歴や既存の受入履歴は保持しています。

## レビュー時の表示手順

1. mainを同期し、以前のプレビューのサーバーを停止する。
2. `cd mobile` で `npm run preview:app -- --port 3000` を実行する。
3. `/app-preview/?lang=ja` または `?lang=en` を開く。旧index.htmlを使わない。
4. 探索の「模型でマシンの使い方を見る」から「視点・再生の詳しい操作」を開く。
5. 「負荷部位」「前から」で胸、肩、腕、腹部、脚の輪郭を確認。筋肉の着色を消した状態も確認する。
6. チェストプレス・ショルダープレス・レッグエクステンション・腹筋で、開始/終了姿勢と三方向の視点を確認する。

実iPhoneでのGL性能・発熱・VoiceOver、写真に対する見た目の受入は別途確認対象です。TestFlight/EASの新規ジョブや配布は引き続き保留します。
