# 人体の質感と、器具を握る手（TASK-047）

ユーザー指定の人体と手の見直しです。

- **指と手のひら**：元の人間の指の形を保ちつつ、実グリップの太さに合わせて表面を滑らかに補正。指が円柱内へ食い込まないようにし、軸方向の指の間隔を保ちます。手首の手前で補正をゼロにして、前腕とのつなぎ目を維持します。
- **握りの見え方**：手の拡大表示にあった不透明な白い接点球を除去。手の中心が合っているかだけでなく、指の表面がグリップの外側にあり、接触する頂点が残っているかも検証します。足の接点表示は維持。
- **肌・顔・目**：控えめな肌の色むら、頬・眉・口元、虹彩/瞳孔を調整。肌・目・ウェアの光の反射を分け、筋肉の着色を切っても表情と立体感が残るようにしました。
- **ウェア**：腰と脚の縁をそろえ、動いた後の実際の人体表面から離す補正を追加。股関節や膝を曲げたときにウェアの縁が体へ埋まり、欠けて見える状態を改善します。

人体の体型・筋肉の配置・骨格・手の基準姿勢は受入済みの形を維持。人体１メッシュ、13,905頂点/27,720三角形/22骨格、全28種目のフォーム、記録キーとスキーマを変えていません。元アセットの衣服以外の位置・法線・スキニング重みは以前のデータと完全一致することを検証します。新しいタイマー、通信、依存ライブラリ、写真テクスチャはありません。接触の補正は教材用で、圧力や力を測ったシミュレーションではありません。

## Antigravityでの確認

main取得後、古いプレビューを停止して再生成します。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja`（英語は `?lang=en`）→ フォームガイド。

1. チェストプレス/ペックフライ/ベンチ/ディップス→詳しい操作→手の拡大。白い球がなく、指と親指が器具を囲むか。開始/終了と前/横/上からを比較。
2. 低速で動かし、指がグリップから滑らず、手首が大きく折れたり前腕との継ぎ目が裂けたりしないか。
3. 全身表示で着色OFF/ON。頬・眉・目や手の質感を確認。胸の着色・筋繊維と既存フォームが維持されるか。
4. 座る/脚を曲げる種目で、腰・脚のウェアの縁が欠けたり、人体へ埋まったりしないか。
5. 他の種目、日英、狭い幅、平面表示、画面を閉じて再度開く操作も確認。
