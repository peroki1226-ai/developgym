# TASK-051: 本格専用の追い込み支援・メイン/ドロップ記録

2026-11-16、日本時間。ユーザー指定の「本格では基本を省き、負荷位置/方法、メインとドロップ、各セットの負荷を追加。初心者には付けない」に対応する。

## 本格モードの構成

本格モードの初期表示は種目変更、種目別の「負荷が逃げにくい位置」「効かせる方法・追い込み方」「代償動作」、仕上げ方、セット記録を中心にする。通常の手順・開始重量・長い解説カードは表示しない。3D模型は任意に開き、閉じた状態ではマウント/再生しない。初心者の詳細操作からも本格の追い込み支援は表示しない。

28種目それぞれに抵抗を保つ位置と、停止・戻し・減量・補助などの方法を日英で追加。器具のカムやレバーが異なるため「必ずここが最大負荷」と断定せず、制御すべき範囲として説明する。余力0のときは追加せず終了する既存の案内を維持。仕上げ方は機械式の減量、複合種目の休憩後の軽い組、補助付きでの補助増加を区別する。

## 記録

- メイン1〜20組。各組に重量・回数・任意の余力（0〜4回以上/未記録）。組ごとに異なる重量/回数を保存できる。
- ドロップ0〜20段階。重量・回数・任意の余力を記録し、どのメインの後に行ったかを指定。
- 同じメインに付くドロップは、直前の段階より重量を下げる。補助付きは補助量を増やす逆方向。空欄・不正数・範囲外・逆転・不正な親を保存しない。
- ドロップが付いたメインを減らす操作は止め、先に削除/付け替えを求める。別の組に勝手に付け替えない。
- 本格入力は通常入力と別の下書き。モード往復で保持、種目を変えたら新しい種目の下書きへ初期化。初心者の通常入力欄・記録方式は維持。

## 「負荷」の意味

計算するのは**入力重量×回数の挙上量**と、本人が記録した余力による**追い込み目安**。各セットと合計、マイページの記録内比較バーを表示する。筋肉の張力、活動率、成長率、実際の関節トルクを測定する数値ではなく、対象筋への割合も推定しない。対象部位は種目のターゲットとして表示する。

| 入力方式 | 計算 |
| --- | --- |
| 通常の重量 | 入力重量×回数。バーベルはバー込み、器具は表示重量に従う。滑車/レバーの実抵抗と区別 |
| 両手インクラインダンベル | 片手重量×回数×2。両手種目として集計 |
| 補助付き懸垂/ディップス | 補助量と回数・余力を保存。補助重量を挙上量に加算せず、重量換算なし |
| 自重ディップス/背筋台 | 加重分のみ。自重だけの組は重量換算なし。体重の抵抗を加算しない |

未入力の余力は未記録のままで、0や任意のスコアを自動設定しない。余力4は4回以上の区分。異なる器具間の挙上量を筋力や刺激の強さとして直接比較しない。

## 保存・互換

既存fitness v4と`@gymfinder/fitness/v1`キーを維持。Workoutに省略可能な`advanced`（内部version1、exerciseId、main配列、afterSet付きdrops配列）を追加し、復元時に検証する。古いv1〜v4の通常/家トレ記録には必須項目を増やさない。

既存のweight/repsは最初のメイン、setsはメイン数を保持する互換用フィールド。現在のマイページではadvancedの全段階を優先表示し、合計カウンターはドロップを除くメイン数と明記する。旧アプリは互換フィールドだけの表示になる。計算結果は保存せず、生データから再計算する。

トレーニング画面だけPageの内容キーを固定し、見出し変更で下書きが破棄されることを防ぐ。また自動スクロールで連続入力のフォーカスが外れないよう、同画面のみkeyboardDismissModeをnoneにする。他画面の既定動作は保持。
