# TASK-030 筋肉の収縮と負荷を見て理解する

2026-11-07（日本時間） / 初回実装の記録

**最新の再改善**: ユーザーの「縮む・伸びる違いが分からない」に対応し、初期表示を両端の距離の比較と片道再生へ変更。力の説明は折りたたんだ。[最新の長さガイド](MUSCLE_LENGTH_COACH.md)を参照。

## 変えた体験

全24種目で、模型の直下に「選んだ筋肉」と、その動作に同期して両端が近づく/離れる筋肉の拡大図を表示する。長い解説までスクロールしなくても、模型と収縮を一緒に見られる。

詳しいパネルは、対象筋、今の身体の動き、筋肉の短縮/伸長、筋肉が引く力、外から受ける抵抗の順に示す。「縮める局面」と「伸ばしながら耐える局面」は、同じ中間姿勢で比較できる。姿勢が同じなら図の長さも同じになり、動く向きと説明が変わる。戻すときも筋肉の力を表す矢印は引く向きのまま保つ。

| 表示 | 意味 |
| --- | --- |
| 筋肉の両端が近づく・上側の内向き矢印 | 短くなりながら力を出す局面 |
| 筋肉の両端が離れる・上側の外向き矢印 | 力を出しながら長くなる局面 |
| 下側の赤い内向き矢印 | 筋肉が引く力。戻すときも逆向きにしない |
| 灰色の外向き矢印 | 筋肉を引き伸ばそうとする外からの抵抗の模式表示 |
| 同じ長さの図・「距離を保つ」 | 姿勢保持。背筋ベンチの脊柱起立筋など |

矢印は筋肉を拡大して力の関係を示した模式図で、人体上の実測力ベクトルではない。重力の向き、ケーブルが滑車へ引く向きと混同しないよう、種目ごとに抵抗源の説明を付ける。補助懸垂/ディップでは「体重は下向き、補助パッドは上向き。補助が強いほど自分で持ち上げる体重は小さくなる」を別説明にした。

四分の一速の再生/一時停止をパネルから操作できる。再生時計は既存のものを共有し、新しいタイマーを作らない。動きを減らす設定では再生を無効化し、局面比較やコマ送りは利用可能。

筋肉を選ぶと、三次元模型の着色・拡大対象・見やすい方向も連動する。SVGフォールバックでも選択筋へ絞る。図の色や太さを負荷量の数値や強弱として扱わず、筋肉の両端が近づく動きと抵抗を受け止める働きを見る。筋節の詳しい模式図は折りたたみから開ける。細い/太いフィラメント自体の描画長を保ち、重なりを変える既存モデルを維持。

## コード

- `domain/muscleLoad.ts`: 全24種の抵抗源、短縮/伸長/切り返し/開始/姿勢保持、妥当な筋肉選択、見やすい後方筋の定義。
- `MuscleContractionPanel.tsx`: 模型直下の拡大図、詳しい比較/矢印/再生/筋節表示。
- `ExerciseDiagram.tsx`: 選択筋と動作位置を共有。模型・図解・拡大図を連動。
- `trainingScene.ts` / `Motion3DView.*`: 選択筋の着色とカメラ対象に反映。選択外の筋肉指定は受け入れず、既存の対象に戻す。
- `HumanFigure` / `ExerciseMotionScene` / `MuscleOverlay`: SVG時の選択筋フィルター。

新しい依存、権限、通信、保存スキーマや器具形状変更はない。TASK-029のハンマーストレングス/実物形状照合は未完了のまま分けて記録する。
