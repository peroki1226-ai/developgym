# 本格モード：効かせるフォームと追い込み方（TASK-046）

ユーザー指定により、全28種目の本格モードに実践ガイドを追加しました。既存の解剖・生体力学・バリエーション解説も残しています。

## 画面と操作

フォーム画面で「本格モード」を選ぶと、模型の近くに「効かせる・追い込む」を表示。初心者画面内の詳しい操作へ切り替えた場合も使えます。初心者の通常表示には追加しません。

- **効かせるフォーム**：種目別の狙い方、戻し方、代償動作を表示。胸なら上腕を寄せる、背中なら肘の運び、脚なら足裏/骨盤の支持など、種目に合う手掛かりにしています。既存の模型と同じ局面に合わせ、今のコツを切り替えます。
- **低速で確認**：動かす局面と戻す局面を別々に再生し、止めて確認できます。既存の再生時計・四分の一速の区間再生を利用し、新しいタイマーや模型を追加していません。観察速度と、実際の運動の戻し２〜３秒の目安は区別しています。
- **追い込み方**：回数・休憩・戻しの目安と「同じフォームであと何回できるか」を表示。３回以上/２回/１回/０回で、その時点の負荷調整の案内が変わります。０回なら追加反復を案内せず、セットを終えます。

| 器具・種目 | 任意の仕上げ法 |
| --- | --- |
| ペックフライ、レッグエクステンションなどの対応マシン | 最終セットだけ負荷を20〜30%下げ、一度だけ制御した追加反復。限界まで続けず余力を残す |
| ベンチ、スクワット、レッグプレスなど | 十分休み、次セットを5〜10%軽くして同じフォームを保つ |
| ディップス、補助付き懸垂など | 次セットの補助を増やす/補助付き種目へ変更し、動作を保つ |

基本の目安は複合種目６〜12回/休憩２〜３分、単関節種目10〜15回/１〜２分、戻し２〜３秒。経験や体調で調整し、すべてのセットに仕上げ法を加える設計ではありません。器具の安全な戻し方・負荷変更・支持・フォーム限界も種目別に説明しています。

既存の本格説明の一部に残っていた「脊柱負荷がほぼゼロ」「血流を遮断」「劇的な筋肥大」などの断定的な日本語７項目も、フォームと負荷制御の説明へ修正し、英語とそろえました。

## 保持するもの

人体/器具の形状・受入済みフォーム、再生とアプリのライフサイクル処理、検索/入力/トレーニング記録の保存キーやスキーマは変えていません。余力の選択は画面内の確認用で、種目やモードを切り替えると初期値２回へ戻ります。言語だけを切り替えた場合は選択を保ちます。余力を永続的な運動記録として保存する機能は追加していません。
