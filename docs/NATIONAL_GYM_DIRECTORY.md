# 全国・多ブランド・地方/女性向け施設検索（TASK-022）

2026年11月4日（日本時間）のユーザー要望に基づき、ネイティブアプリに全国検索を追加しました。既存の5店舗のサンプルと別に、選択した都道府県のオープンストリートマップ施設データを取得する方式です。

## 対応するブランドと地域

ブランド選択は16種類：ゴールドジム、エニタイムフィットネス、チョコザップ、ルネサンス、エバーフィット24、ティップネス、セントラルスポーツ、ジョイフィット、フィットイージー、コナミスポーツ、コ・ス・パ、ホリデイスポーツクラブ、カーブス、ファディー、ボディーズ、ラバ。

これはブランドの検索辞書と公式サイトへの入口の登録で、全支店の登録完了を示す数字ではありません。エバーフィット24はユーザーが提示した `https://www.everfit24.co.jp/` を登録し、千葉県を初期選択します。公式サイトへの実際のアクセス確認は、この環境の接続制限で完了していません。

47都道府県を選択でき、地方の施設も同じ検索導線で扱います。女性向け、公共施設、その他の地域施設で絞り込めます。女性向けブランドと、地図データで女性専用と記載された施設は別の表示にし、支店の利用条件を確定したように表示しません。「その他の地域施設」は登録済みブランドに分類されない施設で、独立経営と確認したという意味ではありません。

## 画面とデータの扱い

- ホームとマップに全国検索の入口を追加。通常検索でサンプルに一致しない語を検索すると、入力を引き継いで全国検索へ進みます。
- 検索ボタンを押した場合だけ、Overpass APIへ都道府県・ブランド・施設種別・検索語を送信。都道府県のISO区域に限定し、最大80件、サーバー20秒/クライアント25秒の制限を設定。起動時の検索や現在地取得は行いません。
- OSMの識別子、返された座標、原名と提供された日英名、情報元・取得日時を保持。施設名や設備を検索語から生成する処理は接続していません。既存のbrandInference/freeSearchServiceの合成データも新画面へ接続していません。
- 設備・ダンベル重量・料金・マッチ率は未確認と表示。既存のサンプルの計算結果と混同せず、根拠のない設備や高い適合率を付けません。
- fitness_centreとsports_centreを対象にするため、スポーツ施設も含まれます。設備の有無や利用条件は情報元・支店へ確認する必要があります。未登録店舗もあり、検索結果が空でも店舗の不存在を意味しません。
- 翻訳済みの施設名がない場合、選択言語のブランド/地域名と識別子で表示し、原名は情報元で確認できるようにします。
- 公式ブランドサイト、登録されたウェブサイト、情報元の地図、施設座標でのGoogle Mapsルートを開けます。OSMのウェブサイト欄は第三者の登録情報として扱います。

## 保存と既存機能

取得施設のお気に入りは専用の `@gymfinder/directory/v1` キーへ保存し、FavoritesとMyPageに反映。元のfitness schema v4・検索設定v1・記録・既存お気に入りは変更しません。破損/未知の保存形式は上書きせず、保存失敗の再試行を用意しています。

検索中の条件変更は前の通信を中断し、遅れて返った古い結果は反映しません。429・通信/部分結果エラー・空の結果を区別し、公式検索への導線を用意しています。日英辞書のエラー再試行ボタンも翻訳を追加しました。送信項目と保存について、プライバシーポリシーのドラフトに追記しています。

- 20スイート/150テスト合格（既存129件＋追加21件）、型チェック、release:check合格。
- iOS/Android Hermesバンドルと、同じネイティブUIのブラウザー確認用エクスポートを生成。
- Chromiumの320/390px・日英・全国検索/ブランド/取得結果/女性向け/お気に入り/エラーの24状態で、言語混在・横はみ出し・実行エラー0。検索入力のフォーカスと、お気に入りの再起動保持を確認。
- 自動テスト・画面確認の取得データはモックです。画像内の施設名にも「画面検証用」と明記し、実店舗検索結果として扱いません。

- 実機iPhone、実データの網羅性、新しい署名付きビルドへの反映は未確認です。既存Build 3を変更・再提出していません。
