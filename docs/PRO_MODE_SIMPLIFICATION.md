# TASK-050: 本格モードの筋収縮・伸長解説を非表示

2026-11-16。ユーザーの「本気モードでは筋肉の収縮とかの解説はいらない」に対応する限定変更。

## 表示の変更

| 本格モードで非表示 | 維持するもの |
| --- | --- |
| 筋肉の短縮・伸長・保持の解説パネル | 3D模型の形状・動作、筋肉の着色切替、対象部位の確認 |
| 筋繊維・収縮の仕組みの詳細パネルと開くボタン | 全方向カメラ、ズーム、再生/停止、速度、位置操作 |
| 脚種目の収縮・伸長の補足表示 | フォーム・戻し方・代償動作の実践的なコツ |
| 解剖学的ターゲットの長文・生体力学本文・収縮種目の分類バッジ | 追い込み方法・余力別案内・種目のバリエーション・記録入力/保存 |

モード名は「本格モード（生体力学）」から「本格モード」へ変更。色の凡例も、本格モードでは対象部位と人体/器具の色だけを短く案内する。筋肉名や動作上の意識まで一括削除するものではない。

`TrainingScreen` が `ExerciseDiagram` に `showMuscleExplanations={!pro}` を渡し、説明パネルを条件付きで描画する。模型の着色と説明の表示条件を分けているため、着色を戻しても本格モードで解説は再表示されない。データ/辞書/収縮機構は削除せず、初心者の詳しい表示で引き続き利用する。

「初心者モード内の詳細操作」と、画面上部で選ぶ「本格モード」は別の設定。本格モードだけ説明を隠し、初心者の詳細操作には既存の学習パネルを残す。器具の高さ/角度の解説（TASK-049）も維持する。TASK-049の設定解説は8d18b14で受入済みとして保全する。
