# TASK-030 再改善：縮む/伸びるを「両端の距離」で見る

2026-11-07（日本時間） / レビュー用

## ユーザーの具体的な指摘

「縮む・伸びる違いが分からない」。初期表示を、筋力の矢印や長い説明から、長い/短い状態の比較と一方向だけの再生へ変更した。

1. **長い状態 / 短い状態**を常に並べる。筋肉の太さや赤さよりも、両端の間隔に注目する。
2. 左端①を同じ場所に置き、右端②が近づけば「縮む」、離れれば「伸びる」と示す。基準の長さを点線、今の距離を両端に目盛りのある線で描く。番号はSVGの線/円で描き、字体不足による欠落を防ぐ。
3. 「長い→短い」を選ぶと長い開始姿勢、「短い→長い」を選ぶと短い開始姿勢を表示する。再生開始時に中間姿勢から飛び戻らない。
4. 四分の一速で**選んだ片道だけ**を再生し、終点で止める。終わった状態を見比べ、反対方向を選んで確認できる。
5. 力の向きや筋繊維の説明は「詳しく見る」に折りたたむ。既存の表示/記録/言語/自由再生や41段階操作を保全する。

大きさは違いを見分けるために強調した模式図。実測の筋肉長、短縮率、負荷や筋力を示すものではない。縮む/伸びるは両端の距離の説明で、筋肉の赤さや太さが力の強さを意味しない。

## 姿勢保持と操作

背筋ベンチの脊柱起立筋を選ぶと、両端の距離を固定し「長さを保って支える」を表示する。比較カード、再生ボタン、終点メッセージも「縮む/伸びる」にせず、身体を動かす/戻す間の姿勢保持として案内する。大臀筋へ切り替えれば長さが変わる説明に戻る。

片道再生は`useExerciseMotion`の既存時計を使用。開始/終点は既存の動作周期上の時刻を利用し、終点を越える次フレームを予約せずに停止する。新しいタイマーや描画ループはない。中断/背景復帰は途中の姿勢と終点を保ち、手動シーク/コマ送りや機種変更はそのレッスンを解除する。動きを減らす設定では自動再生せず、長い/短い状態を手動で比較できる。

旧来の「短縮/伸長を同じ中間姿勢で比較する」ボタンは、初期表示では片道の開始姿勢を選ぶボタンへ置き換えた。自由な中間姿勢の確認は既存の位置バーとコマ送りで行える。詳細の筋力/筋節パネルは単独表示も保全し、アプリ内では選択/操作を重複表示しない。
