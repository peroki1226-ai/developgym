# 添付写真を基準にした胸トレの動くフォームガイド

2026-11-09（日本時間） / TASK-029 今回差分のレビュー依頼

ユーザーが示した「左がペックフライ、右がチェストプレス」の2枚を形状の参考として、既存の `pec-fly` と `chest-press` を更新した。左は頭上の支点でアームを開閉する機種、右は横の重りタワーと下部支点から立ち上がる湾曲アームを持つ機種。2台とも写真と同じ重りスタック式にする。前回のプレートロード式チェストプレスは、今回の写真型へ置き換える。

24種目の項目数・ID・保存キー・記録データは維持し、重複する胸の項目は追加しない。リアデルトフライは既存の独立した項目で継続し、胸のペックフライの名前/主働筋と区別する。

## 左：ペックフライ

- 背面中央の縦長タワー、2本のクロームガイド、15段の重り、選択ピン、細長い背もたれ、座面、後方へ広がる脚を表現。
- 頭上の縦軸支点と調整カム、そこから伸びる左右アーム、長い吊り下げ部、縦の握り、下端の短い曲がりを表現。
- グリップは同じ半径の水平円弧で移動。肘の曲がりを保って胸の前へ閉じる。両手が交差せず、下端同士も衝突しない範囲。
- 閉じる角度と選択された重りの上昇を連動させる。固定タワー・座面・支点と下側の重りは動かない。

## 右：チェストプレス

- 人体の横に寄せた縦長の重りタワー、丸い上部フレーム、15段の重り、細長い背もたれ、座面、低い床フレームを表現。
- 床に近い支点から立ち上がるS字状のアーム、内側へ伸びる握り、軸受、下側のケーブル/滑車、開始用ペダルの形を表現。
- 曲がったアームは剛体として回転し、各部分の長さや形は変わらない。肘を伸ばして前へ押し、両手の横幅は一定。握りと手を接続したままにする。
- プレート/収納ホーンを混ぜず、アームの回転量とスタック上昇を連動。ペダルの操作/設定を再現する機能は今回追加していない。

## 同じ器具を3Dと2Dで表示

3Dはフレームとアームの曲がりを滑らかな一体の鋼管として作る。長い部分は直線を保ち、曲がり角だけ丸める。鋼管の内部、クッションの厚み、金属/クローム/ゴムの材質差も維持。

曲がった形状の頂点データは作成後に再利用し、進捗ごとに作り直さない。機種変更/終了時に、その形状を一度だけ解放する。新しい再生ループは追加しない。

SVGの2D図解も同じ3D骨格と器具位置を投影する。2Dへ切り替えると別の支点・別の手位置へ戻ることを避けた。写真の質感を再現するモードではなく、同じ配置を示す簡略図として表示する。

## 表示名・操作の保全

- 日本語は「ペックフライ」「チェストプレス」、英語は「Pec Fly」「Seated Chest Press」。既存の辞書キーは保持する。
- 胸のペックフライの主働筋は大胸筋へ整理。逆向きの動きはリアデルトフライのガイドを案内する。
- 正面/横/背面、拡大/透過、1/0.5/0.25倍速、コマ送り、片道停止、動きを減らす設定、筋肉着色と記録保存を保全。
- 依存パッケージ、権限、通信、記録スキーマを追加/変更しない。ユーザーの写真・ロゴをアプリへ同梱せず、ローカルの自作形状として表示する。

## 確認手順

```sh
cd mobile
npm run preview:app -- --port 3000
```

同期後に再生成し、`/app-preview/?lang=ja` または `?lang=en` を開く。旧Webプロトタイプ/以前の生成物では今回の模型は表示されない。

胸のフォームガイドから2台を選び、開始/終了姿勢と三方向を確認する。ペックフライは肘の角度を保って閉じ、チェストプレスは肘を伸ばして前へ押すこと、選択分の重りが上昇することを確認する。2Dへ切り替え、手と握りの配置も確認する。

最終検証件数と証跡はDEV_STATEの当日ログと添付JSONを参照。写真から分かる形・配置を基にした学習模型で、メーカーの型番・実測寸法・公式CADとの照合は未実施。ほか22種目をメーカー実機の模型へ変更したという意味ではない。筋肉の変形も教育用の模式表示である。

実iPhoneの描画/発熱/速度/VoiceOverと、ユーザー/Antigravityの見た目受入は別途必要。TestFlight、新規EASジョブ、署名ビルド、配布は実行しない。

## 追加指示：脚の4台と握りの修正

その後に共有された4枚は、左から座席移動式レッグプレス、四十五度レッグプレス、レッグエクステンション、内ももアダクションとして反映した。レッグプレスの1項目に2機種の切替を追加し、種目IDと既存記録を維持する（24種目・25機構）。

- 座席移動式：足台は固定し、背もたれ/座面と人体がガイドに沿って後ろへ移動。重りスタックが上がる。
- 四十五度式：背もたれ/座面と骨盤は固定し、プレートを載せた足台が斜めのレールを上がる。旧模型で骨盤が一緒に動いていた点も修正。
- レッグエクステンション：膝位置の支点を固定し、すね前側に接するローラーとクランクが足とともに上がる。太ももの前を対象表示。
- 内ももアダクション：体幹は固定し、内側のパッド/支持アーム/足置きが脚とともに閉じる。内ももの赤い領域を前寄りからも確認できるよう調整。

脚では選んだ筋肉上に白い収縮方向の矢印を重ね、画面内に「太ももの前」「お尻」「内もも」と長い/短い状態を表示する。戻すときは矢印を外向きにする。矢印と筋腹は既存の動作進捗へ同期し、姿勢を止めると静止、筋肉表示OFFで隠れる。筋の長さ・力の実測値を示すものではない。

### 手の接触

胸の器具形状への「いい」というユーザー評価を保全し、握りを修正した。人体資産の曲げた指の空間から握り中心/軸を求め、実際のグリップ中心・方向へ手全体を配置。手首をその手へ接続し、前腕〜握り位置に手のひらの長さを含める。親指も閉じた人差し指側へ回り込むよう、元の指骨長を維持した事前ポーズを生成する。

握り中心の一致、左右の手、姿勢変化時の連続性を確認する。個々の指の軟部組織・摩擦・接触圧を計算する物理シミュレーターではなく、指を包み込む形へ置いた学習模型。握り中心の一致テストのみを、見た目の受入の代用にはしない。
