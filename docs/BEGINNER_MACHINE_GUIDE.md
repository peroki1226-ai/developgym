# 初心者向けのマシン図解（TASK-021）

ユーザーの「以前の模型のような使い方の説明も入れて」に対応。既存の全12種目のSVG図解と初心者向け説明を、現在のネイティブレイアウトから見つけやすくしました。

## 入口と表示

- ホームの検索操作直下に、小さな人物・マシンの図付き「はじめてのマシンガイド」を配置。
- メニューのガイド入口と「マシンを選んで使い方を見る」から12種目を直接選択。
- ジム詳細の設備一覧では、対応するガイドがある設備にだけ「そのマシンの使い方」を表示。名前の似た別器具への推測マッピングは行いません。
- 選んだマシンを初心者モードで開き、人物・マシン・動く方向の矢印、座席調整、動作手順、既存の注意点を表示。本格モード・他種目への切替・重量/回数/セットの記録も維持します。
- 機種一覧を図解の後へ折りたたみ、図が最初の表示範囲へ入る構成に変更。別の種目を選ぶと図解の先頭へ戻ります。

## 元の画面と記録の保持

ガイドはSafe Area付きの全画面モーダルです。元の画面を破棄せずに開き、「元の画面に戻る」はスクロールに関わらず操作できます。検索語・メニュー検索・フォームなどの入力とスクロールを保持します。ガイド内の人物図と矢印は同梱SVGなので、読み込みにトンネルや外部通信を使いません。

guideIdは表示中の一時状態で、保存スキーマ・店舗データ・既存記録・権限・EAS設定は変更していません。ガイドの説明や図形は既存データを再利用し、新しい運動効果や器具スペックを推測で追加していません。

## 確認したこと

- 18 suites / 129 tests（既存124件＋5件）、型チェック、release:check成功。
- 12種目を日英で直接開く、選択したマシン名で記録する、検索/メニュー入力を保持して戻る、ジム設備から正しい図を開く、通信遮断下で開くことを確認。
- iOS/AndroidのHermesバンドルとレビュー用Expo Webを生成。
- Chromiumの320/390px・日英でチェストプレス/ラットプルダウン/レッグプレスを12状態確認。図解をスクロール前に表示、固定の戻る操作、検索入力保持、言語混在/横はみ出し/実行エラー0を確認。
- 添付画像は同じExpoネイティブUIをブラウザーで描画したレビュー用です。実機iPhone、VoiceOver、モーダルのネイティブ遷移、署名付き新版の確認は未実施です。
