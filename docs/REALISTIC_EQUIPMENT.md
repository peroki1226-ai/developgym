# TASK-029 器具を実物に近い構造・部材へ作り直す

2026-11-09（日本時間） / 今回差分のレビュー待ち・メーカー実機照合は継続

ユーザーの「もっと器具がリアルに近づけてほしい」への対応。人体モデルは維持し、器具のシルエット・支点・材料・可動部を変更した。機種追加やメーカーの完全再現を完了したという意味ではない。

## 見た目と構造

| 対象 | 変更 |
| --- | --- |
| 全24種目の共通部材 | 丸棒のフレームを、角に丸みのある中空角パイプへ。鋼材、クローム、ゴム、クッションの反射/粗さを分ける。金属箱の角を面取りする |
| 座面・背もたれ | 角のある直方体から厚み・丸みのあるクッションへ。背面シェル、縁、座面下の取付金具、調整ノブを追加 |
| プレート | 球や平たい円柱から、中心穴と3つの持ち手穴が実際に開いた板へ。軸受部、収納ホーン、カラーも表現 |
| 支点 | 球形の接合部を、円筒ベアリング、外側のハウジング、六角ボルトへ |
| 滑車・グリップ | ケーブル用の溝を持つ滑車、両側の固定金具、グリップの溝と端部を追加 |
| チェストプレス | 独立したプレートロード式へ再制作。三角形の固定側フレーム、低い左右の支点、左右の剛体アーム、内側の握り、可動アーム上のプレート軸、収納プレート、座席調整機構。重錘スタック/ケーブルを同じ模型に混ぜない |
| スミス | 穴あきプレート、可動部のリニアベアリング端部、引っ掛け金具、フレーム接続ボルト。固定ガイドとバーの鉛直軌道は保全 |
| ラットプルダウン | 頭上の張り出し部と前後の滑車、前方で垂直に下りるケーブル、端が曲がった長いバー、腿パッドの支持構造 |
| レッグプレス/ハックスクワット | 固定フレームと平行なクロームのガイド、スライドするベアリング、可動台への接続、プレート軸。ハックのプレートを固定足台から背面の可動台へ移し、体と一緒に上がるよう修正 |
| 重錘スタック | 下側の重りを接地したままにし、選択分だけ上昇。選択ピン/ノブ、上部ケーブル、側面フレーム。離れたスタックの土台が中央に出ていた位置も修正 |

チェストプレスは新しい支点の円弧に手とアームを接続し、骨長を一定に保つ。左右アームの根元は固定し、プレート軸はアームの同じ位置に固定する。スミスは手が届く範囲の既存の固定ガイド方式を継続。

## 実装

- `mobile/src/three/equipmentGeometry.ts`: 自作の中空角パイプ、面取り部材、クッション、穴あきプレート、溝付き滑車、六角ボルト。ダウンロード模型/画像/テクスチャは使用しない。
- `mobile/src/domain/training3d.ts`: 各機種の部材・固定/可動機構と人体との接続。
- `mobile/src/three/trainingScene.ts`: 部材形状と材質を再利用して描画、終了時に解放。
- `mobile/__tests__/equipmentGeometry.test.ts`: 実際の穴をレイキャストで確認、固定/可動部、レール/重りの連動、スタックの接地を検証。

人体の筋肉着色、三方向、拡大/透過、0.25倍速、コマ送り、片道停止、動きを減らす設定、日英切替、記録保存は維持。保存キー・スキーマ・依存パッケージ・権限・通信は追加/変更しない。

## 実物照合の範囲

ユーザー指定の主基準メーカーはハンマーストレングス、スミスも対象。以前の依頼内容を継続する。

現在の実行環境は接続先制限が適用されており、メーカー公式ページへの実際の接続は403。以前の環境設定案が実行環境へ適用済みとは判断しない。今回作成したのは実際の器具構造を意識した**汎用の学習模型**であり、ハンマーストレングスの型番・寸法・公式CADと照合したレプリカとは表示しない。公式画像やCADの転用もない。

引き続き必要なことは、公式製品写真/図面または現物資料で、対象型番、支点、可動アームの形、プレート軸、座席と握りの寸法を照合すること。特定メーカーとの一致をテスト件数で代用しない。TASK-029全体はIN PROGRESSを維持する。

## 再表示と受入

```sh
cd mobile
npm run preview:app -- --port 3000
```

アプリ共通ソースの `/app-preview/?lang=ja` または `?lang=en` を開く。旧Webプロトタイプは対象ではない。Antigravityの既存生成物へ自動反映されるわけではないため、同期後に再生成する。

チェストプレス、スミス、ラットプルダウン、レッグプレスの正面/横/背面で、部材の違いと接点を確認。低速とコマ送りで手が握りに接続したままか、固定部が動かずプレートと可動部が連動するかも確認。ほか20種目にも共通部材を適用している。

検証件数・実描画の証跡はDEV_STATEの当日ログと添付の検証JSONを参照。ブラウザ検証はExpo Web/Chromium/SwiftShaderで、iPhone実機のGL描画・発熱・速度・VoiceOver検証ではない。見た目の受入も別途必要。TestFlight・新規EASジョブ・署名ビルド・配布は実行しない。
