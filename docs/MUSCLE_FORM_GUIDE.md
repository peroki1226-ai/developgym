# 人体・器具と筋肉の動きが分かるフォームガイド（TASK-027）

2026-11-07（日本時間）。全24種目に、人物/器具の陰影、主な負荷部位の着色、筋繊維と筋節の収縮ガイドを追加しました。

## 利用者に見える変化

- **人物**：肌・胸郭・四肢の陰影と輪郭を整えた、グレーの人体模型です。肩、肘、膝、手、靴と既存の関節位置を維持し、使う部位以外の色を抑えています。
- **器具**：フレームの断面/反射、重り8段とガイド棒/ピン、座面の縁/縫い目、プレートの厚み/ハブ、回転軸とボルト、足元の支持部を表現。接触パッドは身体の前面にも描き、支持位置を読み取りやすくしています。
- **筋肉の着色**：主に使う筋肉を赤茶色で示します。奥の筋肉や短パンの下の部位は透視するように重ねています。着色をオフにすると、グレーの人体/器具でフォームだけを確認できます。
- **筋繊維の動き**：主な筋肉を選び、同じ再生位置で筋腹が短く太くなる/長く戻る模式図を確認できます。さらに筋節を拡大し、長さを保った細いフィラメントが太いフィラメントの間へ滑り込む表示を追加しました。
- **局面の違い**：動作側は「縮みながら力を出す」、戻す側は「伸びながら力を出し、動きを支える」と表示します。戻すときも着色を消さず、力を出して制御することを示します。
- **姿勢保持の違い**：背筋ベンチの脊柱起立筋は、ニュートラルな背中を支える模式表示として長さを固定します。大臀筋は股関節の動作による短縮/伸長を表示。切替ボタンでそれぞれ確認できます。

## 部位の対応

胸のプレス/フライ/ケーブルは大胸筋（インクラインは上部）、ラットプル/補助懸垂は広背筋、ローは広背筋と僧帽筋中部/菱形筋。肩のプレスは三角筋前部、サイド/リアの種目は中部/後部。カールは上腕二頭筋、プレスダウンは上腕三頭筋、補助ディップスは大胸筋/上腕三頭筋を表示します。

レッグプレス/スクワットは大腿四頭筋/大臀筋、膝伸展は大腿四頭筋、膝屈曲はハムストリングス。股関節の開閉は中臀筋/小臀筋または内転筋群、座位のかかと上げはヒラメ筋、クランチは腹直筋。背筋ベンチは脊柱起立筋/大臀筋です。

主働筋の代表的な部位を抜粋した学習用の表示です。全協働筋・個人の筋活動分布を網羅するものではありません。

## 実装と保全

- `domain/muscleMotion.ts`：全24種の主な筋肉、姿勢に追従する領域、短縮/伸長/姿勢保持の状態と筋節描画の座標。
- `MuscleOverlay.tsx`：人体の領域で切り抜いた筋腹/筋繊維。各模型固有の識別子を用い、複数模型の切り抜きが衝突しないようにしています。
- `MuscleContractionPanel.tsx`：主な筋肉の選択、筋繊維/筋節の拡大、局面説明。既存の再生進捗を受け取り、新しいタイマーは作りません。
- `HumanFigure.tsx`、`ExerciseEquipment.tsx`、`ExerciseMotionScene.tsx`：人体の陰影、器具の材料/接点、着色の統合。器具描画は同じ支点/接点の式を使う専用部品へ分離しました。
- `ExerciseDiagram.tsx`、日英辞書、図解/再生テストを更新。

通常/半速/4分の1速、41段階コマ送り、停止位置からの連続再開、関節拡大、背景/非表示時の停止、動きを減らす設定、入力/記録保存を維持。追加依存・ネット画像・権限・保存形式・EAS設定・旧Webの変更はありません。

## 表示の意味と確認範囲

色は部位の目印で、強いほど赤くなる実測の負荷/筋活動ヒートマップではありません。長さ・太さ・収縮率も描画上の模式表現です。全体は陰影を付けた二次元ベクトル図で、個別メーカーの器具を三次元スキャンしたものや、精密な解剖シミュレーターではありません。この区別は画面内にも明記しています。

全25スイート/277テスト、型検査、release:check、両OSバンドル生成成功。320/390px×日英×24種の96状態/480姿勢、30対象部位の可視着色、着色オフ時に模型の有彩色0を確認しました。姿勢保持の固定長、往復の説明、3速度/位置指定、言語分離・描画エラー0も確認。結果をDEV_STATE.mdと添付`gymfinder-muscle-guides/`へ記録しています。画面資料は同じReact Native UIのExpo Web/Chromium描画であり、iPhone実機録画や署名済みIPAではありません。iPhone上の滑らかさ/VoiceOverは未確認です。TestFlight向け操作、新規リモートビルドは実行せず、直接配布もユーザーの明示指示まで待機しています。
