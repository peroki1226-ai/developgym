# バーを握る手の改善 — TASK-064

対象は `mobile/` の共通3D人体。バーの上に指を置くように見える握りを、4本の指で包み、親指を人差し指へ対向させる形へ修正する。

- 指の長さが違うため、全指へ同じ角度を与える方式から、各指の骨長を保って共通の握り面へ沿わせる方式へ変更。関節の向きも揃えて指のねじれを抑える。親指は指先の目標へ収束を確認して対向させる。
- 手全体を外へ膨らませる処理を、バー径に合わせた滑らかな接触処理へ変更。指の幅方向と手首の固定点を維持し、手首へ向けて変形を弱める。陰影用法線も同じ変形へ追従。
- スミス／通常ベンチの金属バーから、実物にない太いゴムグリップと指に重なる金属リングを除去。把持半径を実際のシャフトと一致させる。マシンの握りは手の幅を覆う長さへ調整。
- 手の辺だけを一段細分化し、指先の角ばりを低減。1個の人体メッシュを継続使用し、表示時33,230頂点・66,370三角形、16ビットインデックスを維持する。頂点・インデックス・表示用バッファは再生中に再生成しない。

## 保持するもの

人体アセットの手3,094頂点以外の20,906頂点は位置・法線・陰影・ウェイトを変更しない。骨格、元の24,000頂点／47,910三角形のトポロジー、衣服、部位マスク、バー軌道、先行TASK-063の手幅・下端肘90度、再生操作、記録・言語切替は維持する。把持点の基準変更に合わせて、表示時の手首と前腕は同じ接点へ追従する。

旧固定値から手を除いた保護検査は、変更前の `cc8247b` のアセットで計算した値を使用する。新たに、手以外の全20,906頂点をまとめた固定値検査を追加する。新しい手の決定性、手元の細分化後の閉じた接続、両手の接触・有限値・異常に長い辺の不在、実際のシャフト径、法線と変形の整合性も検査する。

## アセット再生成

既存のCC0 MakeHuman入力を使用し、受入済みの人体から手だけを置き換える。

```bash
git show cc8247b:mobile/src/data/human/makehuman.json > /tmp/gymfinder-hand-base.json
python mobile/scripts/build-human-model.py \
  --source-root /path/to/pinned-makehuman-checkout \
  --hands-only-from /tmp/gymfinder-hand-base.json \
  --output mobile/src/data/human/makehuman.json
```

`--source-root` は既存README記載の固定コミットを指す。手以外の人体データは元アセットを保持し、指の各骨長と親指目標への収束を生成時に検査する。
