# ディップスの追加深化と胸の寄せ方（TASK-043）

ユーザー指定のディップスだけを変更。胸コースの同じ種目・記録・再生操作を使います。

## 動きと表示

- **深く沈む**：模型内の下端骨盤高を46→43へ。上端57.8を保ち、上下移動量は11.8→14.8（約25%増）。手と器具は固定、腕の長さと後ろに浮かせた足を維持します。数値は模型座標で、利用者全員に必要な深さを示すものではありません。
- **上端で胸を寄せる**：押し上げの最後35%で、上背部を滑らかに0→8度だけ前へ曲げます。胸郭・首・肩・腕の付け根が追従し、手はバーを握ったまま。腰側の向きと骨盤の位置を崩す大きな全身の丸め込みにはしません。
- **みぞおちの少し上を意識**：大胸筋下側の実際のスキン面に沿う矢印と、胸骨下部付近の目印を終点近くに追加。胸の内側・下側を寄せるイメージを日英で説明します。筋肉が腹部へ移動したり、負荷が一点に集中することを測定した表示ではありません。
- **動作と同期**：沈む→押し上げる→軽く寄せる、戻す→寄せをほどいて下げる、を既存の再生時計で連動。戻す区間や着色OFFでは終点の目印を隠し、既存の筋繊維の伸張表示を使います。

通常・半速・四分の一速、停止/再開、手動位置合わせ、伸びた/縮んだ姿勢、６方向・自由回転・ズームは維持。人体データ、他27種目、保存キー/スキーマ、過去の記録、依存ライブラリは変更していません。
