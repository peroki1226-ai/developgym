# TASK-029 器具形状の実物照合と再制作

2026-11-07（日本時間） / ユーザー差戻し・IN PROGRESS

## 現状の不足

現在の24種は汎用模型で、メーカー/型番/写真/図面と照合した実機モデルではない。前回の334テスト、三方向のWebGL描画、筋肉の可視ピクセル確認は機能の検証であり、器具形状の正しさを保証しない。この監査時点では模型コードを変更していなかった。後続のユーザー指定（ハンマーストレングス優先・スミスも対応）とスミスの部分修正は[今回の修正と残り](HAMMER_SMITH_GUIDE.md)を参照。以下の監査表は修正前の記録。

`mobile/src/domain/training3d.ts` を監査した結果:

| 箇所 | 確認できた不足 | 再制作で必要なこと |
| --- | --- | --- |
| `seat` / `back` / `stack` | 共通寸法・形状の座面、パッド、重り塔を多数の器具へ配置している | 製品ごとの外形、支柱配置、座面形状、カバー、座席調整部を写真/寸法と照合 |
| `incline-smith` / `power-rack` | 同じ分岐のフレームを使用。スミス専用ガイドレール/スライダーを生成していない。Jフックもバーに追従する | 実際のガイド傾斜、固定フレーム、可動スリーブ、フック/ストッパー、ラックとの構造差を再現 |
| `leg-extension` / `seated-leg-curl` | レバーと軸位置を人体の膝/足首から生成し、実機の片側駆動部/軸/ローラー機構と照合していない | 実機の固定回転軸、レバー形状、足首/腿パッド、駆動カム/カバーを確認 |

## 基準資料

まず1台のメーカー/シリーズ/型番を特定し、その機種の実物形状を再制作・確認してから他の器具へ展開する。種目名だけでは形が一意に決まらない。たとえばプレート式とウエイトスタック式を混ぜて同じ製品模型と扱わない。

必要な資料はメーカー名・型番が分かる製品情報、または再現したい器具の実物写真。最初は器具全体が写った斜め前の写真1枚で対象を特定し、裏側や寸法が判断できない箇所だけ追加確認する。写真から見えない機構を推測して「一致」と報告しない。

メーカー公式資料へのHTTPS取得は、この環境のネットワーク許可先制限により403で失敗した。現時点では公式写真や寸法を取得/確認できていない。出典未確認の画像や、生成画像を実機の証拠として使用しない。

## 再制作と受入

1. 機種名、参考資料、判明した寸法/不明部分を記録する。
2. 実物の固定フレーム、座面/パッド、支点、可動部、ケーブル/レールを先に作る。
3. その器具の座面/握り/足台に人体を合わせる。人体に合わせて器具全体の支点を動かさない。
4. 前/横/後の開始・中間・終点を実物資料と比較する。未確認の裏面を一致済みとしない。
5. 低速再生中のバー/アーム/ローラー、手足の接触、貫通、固定部の不動を検証する。
6. 同じ視点の実物と模型を並べ、ユーザーが形状を確認してから他機種へ展開する。

三方向、手足への拡大、筋肉着色、低速/コマ送り、保存/日英分離は保全対象。TestFlight、新規クラウドビルド、配布は未実行。実物資料と模型の差が解消するまでは形状対応を完了扱いにしない。
