> 最新の2026-11-09差分は [REALISTIC_EQUIPMENT.md](REALISTIC_EQUIPMENT.md) を参照。以下は前回の修正記録です。メーカー実機照合は引き続き未完了。

## ユーザー指定と実装範囲

主な基準メーカーを**ハンマーストレングス**とし、**スミスマシンも対象へ含める**。メーカー名は確認済みなので、再回答を着手条件にしない。

今回実装したのはスミスマシンの構造修正。従来はラックと共通だった描画を分離し、固定ガイドと可動バー、受け金具の違いが分かるようにした。

| 要素 | 今回の動作 |
| --- | --- |
| 角パイプフレーム・2本の垂直ガイド | 動作中も固定 |
| 可動スリーブ・水平バー・プレートスリーブ/カラー | 同じ高さでガイドに沿って上下 |
| 受け金具・下部の安全ストッパー | バーとは別に固定 |
| 収納ホーン・ベンチ支持/調整部 | 固定 |
| 手首 | 握り幅を調整し、両手がバー上を保つようにIKで解く |
| ベンチ | 背面/座面幅を調整。バーに追従して動かさない |

これは汎用の垂直ガイド方式であり、メーカー製品の写真/図面との一致はまだ確認していない。ハンマーストレングス製スミスとして表示せず、他の23種を同メーカーの実機模型へ変更したとも扱わない。前/横/後、接点/筋肉への拡大、透過、低速/コマ送り、保存/日英分離を維持。

## ハンマーストレングスの再制作

最初の照合候補は、プレートロード式のアイソラテラル・ベンチプレス。公式資料で型番/形状を確認してから、固定フレーム・左右の可動アーム・プレート軸・座面と握りの配置を作り、人体を器具へ合わせる。プレートロード式とMTS/セレクトライズド式を同一模型へ混ぜない。候補選定は製品形状を確認済みという意味ではない。

**未完了**: 公式資料の取得、製品/型番の確定、実物との形状照合、ハンマーストレングス模型の再制作と受入。形状の一致をテスト合格数で代用しない。
