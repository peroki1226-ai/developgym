# 大胸筋の表示位置と筋繊維の修正（TASK-033）

胸の筋肉が低く見えるというユーザーの指摘に対応しました。

## 原因と修正

従来は、元モデルの「大胸筋を膨らませるモーフ」の変位量を着色の強さに使っていました。その値が胸の下側に偏っており、胸全体の領域として使うと着色の中心が低くなっていました。

今回は同じ人体表面の鎖骨と上腕付け根を基準に領域を生成します。大胸筋は鎖骨の下、胸郭前面に置き、胸骨側から脇へ向かって下縁が上がる形にしました。腹部との境界と胸骨中央の隙間を保ち、上胸部はこの範囲の上側に限定しています。隣接する表面頂点を使って境界をなじませています。

筋繊維と局所変形の軸も、胸を水平に横切る向きから、胸骨・鎖骨側から上腕へ集まる扇形の向きへ変更しました。簡略SVGの正面・側面・ベンチ姿勢でも、胸部を上げ、上胸部と全体の領域を区別しています。

## 保持したもの

人体の元の頂点・骨格・スキニング重み・指/握り・衣服・ライセンス情報は変更していません。生成済みJSONでは胸と上胸部の2マスクだけを更新し、他15領域のマスクも保全しています。器具・種目・保存データ・初心者の4段階ガイド・低速再生・記録・日英の機能も維持しています。

## 再生成

フル変換と部分更新は同じ `mobile/scripts/human_pectoral_masks.py` を使用します。

```sh
python mobile/scripts/human_pectoral_masks.py
python mobile/scripts/human_pectoral_masks.py --check
```

部分更新は同梱済み頂点と骨格を使うため、上流モデルの再ダウンロードは不要です。NumPyは既存のモデル変換時と同様に必要で、アプリの依存や通信は追加していません。

## 見た目の確認

`cd mobile` → `npm run preview:app -- --port 3000` → `/app-preview/?lang=ja` または `?lang=en` を開きます。探索の「模型でマシンの使い方を見る」から「視点・再生の詳しい操作」を開き、「前から」「負荷部位」「開始姿勢/終了姿勢」で比較できます。ペックフライ、インクライン、ケーブル、補助ディップでも位置を確認してください。

変更前後を同じ実アプリ・同じカメラで撮影した画面は `gymfinder-chest-placement` に添付しています。旧 `index.html` ではなく、ネイティブと同じExpoアプリを再生成してください。

この表現は学習用の筋肉領域・収縮の模式表現です。個人の解剖学的な差、筋束長、筋力や筋活動量を実測するものではありません。ブラウザの実描画確認と、ユーザー/Antigravityの見た目受入・実iPhoneでの視認性は分けて扱います。TestFlight/EAS配布は保留を維持します。
