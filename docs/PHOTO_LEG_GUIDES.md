# 写真の脚4台・収縮の即時表示・胸の握り修正

2026-11-09（日本時間） / TASK-029・TASK-031 差分レビュー依頼

ユーザーが追加した写真は、左から座席移動式レッグプレス、四十五度のプレート式レッグプレス、レッグエクステンション、内ももアダクション。胸2台の器具形状への肯定を保全し、脚4台と握りを修正した。

## 機構と対象筋

| 写真の器具 | 固定する部分 | 動く部分 | 主に確認する筋肉 |
| --- | --- | --- | --- |
| 座席移動式レッグプレス | 足台、ガイド、重りタワー | 座面/背もたれと人体が後方へ移動、選択分の重りが上昇 | 太ももの前、お尻 |
| 四十五度レッグプレス | 座面/背もたれ、骨盤、レール | プレートを載せた足台が斜めに上がる | 太ももの前、お尻 |
| レッグエクステンション | 座面、膝の支点、重りタワー | すね前側のローラーとクランクが膝伸展に連動 | 太ももの前 |
| 内ももアダクション | 体幹、座面、重りタワー | 内側パッド、支持アーム、足置きが脚とともに閉じる | 内もも |

レッグプレスの既存項目を「レッグプレス」とし、ガイド内に「座席が動くタイプ」「四十五度タイプ」の切替を追加した。切替時は開始姿勢へ戻る。元の24種目IDと記録スキーマは維持し、表示する機構は25構成になる。切替はガイド内の状態であり、保存済み履歴を別種目へ分割しない。機種間で重量を一律に扱わないよう開始負荷の案内も最軽量での動作確認へ変更。

## 縮む・伸びるをすぐ確認

- 選んだ対象筋だけを赤茶色にし、人体上に白い向きの矢印を重ねる。
- 画面内に「太ももの前」「お尻」「内もも」と、長く伸びた状態/短く縮んだ状態を表示。戻す間は伸びる向きを表示する。
- 選択した筋肉のマスク/軸に筋腹の変形を結び直した。内転筋の前寄りの内側も見えるようにし、別の筋肉の変形に引きずられないよう修正。
- 内側パッドが対象を隠しすぎないよう高さを調整。矢印は学習用の重ね表示とし、皮膚や器具の裏へ消えないよう描画。
- お尻の経路は、レッグプレスの股関節周囲を回り込む模式的な経路へ修正。押すときに誤って長くなる直線の弦の計算を避けた。

矢印、筋腹、状態表示は既存の進捗に同期。姿勢を止めると静止、戻すと逆向き、筋肉表示OFFで隠れる。独立した脈動や新しい再生ループは追加していない。筋束長・筋力・筋活動量を実測した表示ではなく、向きと位置を理解するための学習表示。

## グリップを包む手

- 元の人体の曲げた指から握り中心/軸を求め、実際の器具のグリップ中心/軸へ手を合わせる。
- 前腕から握り位置までに手のひらの長さを含め、手首を手へ接続。旧来の一律の短い手首オフセットを修正した。
- 事前ポーズ生成時に、親指を閉じた人差し指側へ回り込ませる。指骨長を保つCCDを使用し、実行時に指を毎回生成しない。
- 握りの中心、左右、姿勢変化の連続性と実際の拡大表示で確認。中心の一致だけを、見た目の受入の代用にはしない。個々の指の接触圧/摩擦/皮膚変形を解くシミュレーターではない。

人体の出典/CC0表記は既存のまま保全し、追加の握りフレームと親指ポーズも再生成スクリプトへ記録した。写真/ロゴや外部CADは同梱していない。

## 受入手順

```sh
cd mobile
npm run preview:app -- --port 3000
```

同期後にアプリ共通ソースから再生成し、`/app-preview/?lang=ja` または `?lang=en` を開く。旧Web版・以前の生成物を確認しない。

胸2台で開始/終了姿勢と握りを三方向から確認。脚はレッグプレスの2機種を切り替え、座席/足台の動きの違いを確認。エクステンションとアダクションも開始/途中/終了、収縮/戻し、0.25倍速、筋肉選択/表示OFF、2D図解、記録保存を確認する。

最終件数と証跡はDEV_STATEと添付JSONを参照。写真で分かる形/配置に基づく模型で、メーカー型番/実測寸法との照合、実iPhoneのGL/発熱/速度/VoiceOver、ユーザー/Antigravityの見た目受入は未完了。TestFlight/EAS新規ジョブ/署名ビルド/配布は実行しない。
