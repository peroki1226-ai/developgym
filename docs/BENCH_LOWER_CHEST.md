# ベンチプレス：バーの下端を胸下部へ（TASK-045）

ユーザー指定の「下ろしたときに胸の下部へ来る」修正です。通常のベンチプレスだけを対象にしています。

- 停止点を前腕の長さから逆算する方式から、**実際の人体メッシュの胸下部・胸骨下部に合う位置**へ変更。模型内の前後座標は約−15.26→−17.7。頭側/足側の数値に頼らず、大胸筋下側のスキン面の目印とバーの位置が合うことをテストします。
- 握り幅・バーの高さ・上端は維持。下端の前腕はほぼ垂直（傾き約4度）、肘の開きは平面投影で約69度。手は同じバーを握ったまま、押すときは肩側へ、戻すときは胸下部へ同じ軌道をたどります。
- 日英の開始位置、戻す説明、動作中の確認文を「胸の下部」に統一。バーを胸へ弾ませる表現にはしません。
- 水平ベンチ、頭/上背部/お尻/左右の足、他27種目、再生操作、記録データは変更しません。

mainを取得し、古いプレビューを停止後に再生成してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja`（英語は `?lang=en`）→ 胸コース → ベンチプレス → 伸びた姿勢 → 上から。胸の拡大表示でも下端位置を確認できます。半速で往復させ、胸下部から肩側へ押し、胸下部へ戻るかレビューしてください。
