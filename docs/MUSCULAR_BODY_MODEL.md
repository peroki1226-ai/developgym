## 変更した体験

「模型の人間を、筋肉の動きが分かる筋肉のある模型に変えて」という要望への実装。滑らかな人体表面の着色帯を、人体に沿う個別の筋肉の立体面へ置き換えた。全身の筋肉は灰色で形と境目を残し、対象筋だけを赤茶色にする。

- 胸の扇状の筋肉と上部、腹筋の区切り、体側、背中の広背筋/肩甲骨周辺/脊柱沿い、臀部と外側の股関節。
- 肩の前/横/後、上腕の二頭筋/三頭筋の領域、前腕、太ももの前/後/内側、ふくらはぎとすね。
- 筋腹の膨らみ、白い端部、筋繊維の線を別の面として見せる。64の筋肉面の領域で構成し、実際の筋肉数を64個と定義するものではない。

選択した筋肉では、動作進捗に合わせて筋腹の描画範囲と厚み、筋繊維の長さ/位置が変わる。戻すときは同じ進捗を逆向きにたどる。脊柱起立筋など姿勢保持の対象は、進捗による筋腹/繊維の変形を一定にする。色の濃さを力の数値として変更しない。

「着色を非表示」にしても、灰色の筋肉の形と筋繊維は残る。三視点、器具の透過、筋肉選択と拡大、低速/片道再生・終点停止、長さガイドは維持。上腕三頭筋を選んだときは後ろ側の見やすい視点にする。部位によっては横から見た方が形が分かりやすいため、画像に使った視点も示す。

SVGフォールバックでも対象以外の筋肉を灰色の面で描き、対象を最後に重ねて見失わないようにする。着色を消しても筋肉の境目は残る。

## 実装

- `mobile/src/three/anatomicalMuscles.ts`: 既存の人体表面に沿う筋肉面、繊維、筋腹の模式変形。胸や背中の扇形、腕脚の筋腹、腹筋の区切りを分けた。
- `trainingScene.ts`: 帯状の着色を除き、新しい筋肉面を描画する。骨格、手足の接点、器具やカメラの操作仕様を変えない。
- `muscleMotion.ts` / `MuscleOverlay.tsx` / `HumanFigure.tsx`: SVG時も全体の筋肉形状を表示。対象外の灰色の筋腹は進捗による変形を一定にし、対象だけを動作と連動。

すべての筋肉面と筋繊維を**二つの描画オブジェクト**にまとめ、頂点バッファを再利用する。表面9,792頂点、繊維8,960頂点。別の再生ループは追加せず、既存の進捗だけで更新する。部位/機種を変えても筋肉バッファを使い回し、終了時は頂点・線・材質を一度だけ解放する。描画オブジェクト数と、影を含む描画回数は別の指標。
