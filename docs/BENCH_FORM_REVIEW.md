# ベンチプレスのフォーム再点検（TASK-044）

対象は通常のフリーバーベル・ベンチプレス（`barbell-bench-press`）だけです。写真型スミスのインクライン、胸ディップス等は変更しません。

## 見直した動き

- **下ろす位置**：従来はバーが腹側へ寄りすぎていました。胸の中央よりやや下の前へ止める位置に変更。模型内の前後位置は約−12.2→−15.26、高さは36.4→34.8です。胸に弾ませず手前で止める初心者向けの動作例であり、全員に同じ深さを指定する数値ではありません。
- **手首と肘**：左右の握り幅を40→36へ調整し、下端では正面・横のどちらから見ても手首/握りの真下へ肘が来るよう逆運動学の曲げ方向を変更。上腕の体幹に対する開きは、下端の平面投影で約57度です。腕の長さを伸縮してバーへ合わせる方法は使いません。
- **押す軌道**：胸側から少し肩側へ戻る浅い曲線。前半で前後移動を多めに、上端近くではほぼ垂直に動き、肩関節の上で止めます。戻す際は同じ軌道を逆にたどります。手・バー・両側プレート・青い軌道矢印が同じ姿勢を参照します。
- **支持**：前回指定の床と平行なベンチを維持。頭・上背部・お尻・両足は動作中に移動しません。ラックとセーフティも固定です。日英教材に肩甲骨を軽く寄せて下げること、自然な腰の隙間を保つこと、親指を巻き手のひらの付け根側でバーを支えることを明記しました。
- **動作中の確認**：「下端：前腕を立てる」「押す：少し肩側へ戻す」「上端：肩の上で静かに支える」「下ろす：胸へ戻す」を既存の時計/手動スライダーに同期。模型を動かしながら確認できます。

通常・半速・四分の一速、停止/再開、手動位置合わせ、６方向/自由視点/拡大、筋繊維表示、平面表示、トレーニング記録は維持。人体アセット、保存キー/スキーマ、依存は変更しません。模型は教育用の例で、握り幅や可動域は体格に合わせて調整します。

## Antigravityのプレビューで確認

main取得後、古いプレビューを停止して再生成します。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`http://localhost:3000/app-preview/?lang=ja`（英語は `?lang=en`）→ 胸コース → ベンチプレス。

1. 伸びた姿勢→横/正面/上から。バーが腹や首へ流れず、胸の前で止まるか。下端で前腕がほぼ垂直か、肘を真横へ張りすぎていないか。
2. 本格モード→「器具を透かす」。プレートやセーフティの奥に隠れる肘・手首も確認できます。台は水平、頭・上背部・お尻と足裏が安定しているか。
3. 半速/四分の一速で１往復。押す前半の肩側への移動と後半のほぼ垂直な軌道、戻す動作と説明が一致するか。
4. 停止/再開・スライダー・視点切替・平面表示でも姿勢と確認ポイントが同期するか。旧記録と重量入力は保持されるか。

凍結中の `index.html` や古い生成ファイルでは確認できません。実表示の画像・動画・検証ログは `/workspace/attachments/gymfinder-bench-form/`。実iPhoneの見た目/性能の受入は別途です。新規EAS署名ビルド・TestFlight提出・外部配布は実行しません。
