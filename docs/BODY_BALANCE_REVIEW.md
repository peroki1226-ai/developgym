# 四方八方から見た人体バランスの再修正（TASK-047 再レビュー）

ユーザーの「背中が反り過ぎる、体のバランスが悪い」という指摘への追加修正です。同じTASK-047を再開し、前回の握り・質感だけでなく、人体形状と骨格への載せ方を直しました。

## 修正内容

- **胸郭と骨盤のつながり**：背骨の区間ごとに異なる元モデルの前後位置を使っていたため、胸郭が骨盤や肩の付け根に対して前へ張り出していました。骨盤から上背部まで共通の連続した基準へ変更。中立姿勢では全区間が同じ変換を共有し、運動として意図した屈曲は残します。
- **首**：平面図の頭の横ずれを、そのまま立体の後傾へ変換する処理を修正。首・頭を上背部の向きへそろえ、顎が上がり過ぎる姿勢を減らしました。
- **体型**：`balanced-athletic-adult-v5` を生成。追加していた筋腹の膨らみを上腕・太もも・ふくらはぎで抑え、上胸部/腹部の強調を弱めました。腰の後ろのくぼみを浅くし、ウエストをわずかに広げています。筋肉を学べる輪郭は残します。
- **ベンチ**：水平な台、上端、胸下部の前後位置と握り幅を維持。新しい胸郭形状からバーが浮き過ぎないよう、下端高を34.8→33.3模型単位へ調整。胸下部との位置照合・前腕のほぼ垂直・手の握り・骨長も再検証しています。
- **握り・ウェア**：前回の指/手のひらの適合と、人体に追従するウェアを維持。手の元形状・握り基準・骨格・元データ23ファイルは同じです。人体１メッシュ/13,905頂点/27,720三角形/22骨格も維持しています。

新しい形状から法線・筋肉マスク・衣服の重みと追従点・陰影をまとめて再生成しています。前の形状のマスクをそのまま貼ったものではありません。既存の全28種目、初心者/本格モード、記録・検索データ、日英表示は維持します。新しい描画時計・外部モデル取得・依存ライブラリは追加していません。

これは教材の人体と姿勢の見直しであり、全員に共通する体型や医学的な安全域を定義するものではありません。体型の好ましさ・自然さは実画面での受入をお願いします。

## Antigravityでの確認

main取得後、古いプレビューを停止して再生成してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja`（英語は `?lang=en`）→ フォームガイド → 詳しい操作。

1. 「全体を収める」→ 着色OFF →「器具を透かす」。前・左・後ろ・右・上・下から、腰のくぼみ・胸郭/骨盤の位置・頭の傾き・左右の肩と手足を比較。
2. チェストプレスとラテラルレイズを横から。胸を張り出し、腰を折って首を後ろへ反らした見え方が減っているか。
3. ベンチ、スクワット、バックエクステンションでも開始/終了を比較。必要な屈曲や前傾まで消えていないか。ベンチのバーは胸下部の前へ来るか。
4. 自由回転で360度と上下も確認。再生して、動作途中に体型が跳ねたり首が反転したりしないか。握り・衣服・既存の筋繊維表示も確認。
