# 動くフォーム模型ガイド：12種類から24種類へ（TASK-024）

2026-11-06（日本時間）。既存の模型の色・図解カード・再生/一時停止・半速・姿勢/位置操作を維持し、ガイド対象を24種類に増やしました。

## ガイドと操作

ホーム、メニューのガイド一覧、フォーム画面の部位フィルタから選択できます。種目一覧の「全24種目」は実際のカタログ件数から表示し、開始/終了姿勢を切り替えたり、途中を指でなぞって確認できます。

追加器具にも座席/パッド設定、初心者手順、注意点、開始負荷の目安、本格モードの解剖・動作説明・バリエーションを日英で用意しました。負荷は機種差があるため、新規マシンは最軽量からの確認、補助マシンは十分な補助、背筋ベンチは追加重量なしを案内します。

既存12種類とそのID、保存形式、記録・検索・戻る際の入力保持を維持。ジム検索の設備カタログやマッチング種目の追加はこのガイド拡充の対象に含めていません。

## 実装

- `mobile/src/data/equipmentAdditions.ts`に追加ガイドを置き、既存`EQUIPMENTS`へ追記。
- `exerciseMotion.ts`と`ExerciseMotionScene.tsx`に12種類の座標と器具を追加。全24種類のカタログと動作モデルを対応させ、動く部位を使って軌道を生成。
- 部位フィルタと共通の再生コントローラーを再利用。動きを減らす設定、背景/非表示時の停止、一覧用の静止模型を維持。
- 依存・権限・EAS設定は変更なし。新規リモートビルド、TestFlight提出/招待は行っていません。
