# 写真を参考にしたスミス・インクラインベンチプレス（ユーザー指定 / TASK-042）

胸コースの既存 `incline-bench-press` を写真を参考にしたスミス式へ変更しました。胸コース８種・全２８ガイドを維持します。

- 銀色の門形フレーム、左右の固定レール、可動スリーブ/ベアリング、掛け位置、下部ストッパー、左右のプレートと後方の収納ペグ。
- 約３０度の黒い背もたれ、頭まで支えるパッド、別の水平な座面、調整材・脚・床面の支持。ベンチ位置と握り幅をこのレールの位置へ合わせ、両足を床へ固定。
- バー・両手・可動部・プレートは同じ高さで垂直移動し、前後左右へ軌道がずれません。プレートは支柱の外側へ置き、フレームを貫かない構成です。
- 手は実際のグリップへ合わせて握り、胸の収縮・軌道矢印・低速・停止/再開・手動操作・６方向/自由回転/拡大・記録を継続使用。平面表示も台とフレームの実際の面を投影します。

## 教材・検索・保存

日英の機種名・準備・手足・各局面・狙い・注意点・コツ・記録方法をスミス用に変更。機種の実効バー重量と補助を確認し、左右のプレートを含む合計を記録する説明です。一般バーの２０キログラムを自動的に当てはめません。

`m-incline-bench` の必要器具は `incline-smith` に変更し、フリー用のベンチや通常ラックだけで実施可能とは判定しません。既存の２つのインクラインメニュー入口は同じ写真型ガイドへ接続し、既存メニュー選択IDは保持します。店舗の保有設備を推測で追加していません。

以前のフリー種目の辞書キー `chest.inclineBench.name` は保存済み履歴のため残します。今回からガイドと新しい記録は `chest.inclineSmith.name` となり、過去の種目名・重量・日時をスミスの記録へ書き換えません。保存キーとスキーマの変更はありません。

写真を参考にした教育用模型です。メーカーのCAD寸法・特定機種のバー重量・補助量を断定するものではありません。

## 再表示と受入

mainを同期し、旧プレビューを止めて再生成してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja` と `?lang=en`。凍結中の index.html は対象外です。

1. 胸コース→スミス・インクラインベンチプレス。斜め/横/上からフレーム・レール・傾斜ベンチを確認。
2. 開始/終了姿勢、低速再生と手動操作。手の握り、固定レール、可動部とプレートの連動を確認。
3. 自由回転・ピンチ・全体復帰・平面表示を確認。
4. 新しい記録を保存し再読み込み。以前のフリー種目の記録を原文/重量のまま保持することを確認。

実iPhoneの見た目/性能の受入は別途です。新規EASビルド・TestFlight提出/配布は実行しません。
