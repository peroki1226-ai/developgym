# 胸５種目の初心者フォームガイド（TASK-035）

対象は mobile/ の実アプリです。旧 index.html のデモではありません。

## 開き方と学び方

探索の「胸の５種目を模型で学ぶ」→「胸の５種目から選ぶ」。模型の「姿勢 → 手 → 足 → 動作」を順に確認できます。選択肢は普段は折りたたみ、模型を見やすくします。戻ると元の検索入力を保持します。

| 種目 | 模型と説明の重点 |
| --- | --- |
| インクラインダンベルプレス | 約３０度のベンチ、前腕を垂直に保つ独立ダンベル、上胸部の強調 |
| チェストプレス | 既存の写真参考マシン、胸の中央のグリップ、背もたれ・手首・肘 |
| ペックフライ | 既存の写真参考マシン、肘角度を保つ水平内転、開きすぎの修正 |
| ディップス（胸を狙う） | 固定した平行棒に対して体が上下、軽い前傾、曲げた膝と浮いた足、補助付きへの入口 |
| インクラインハンマープレス | 左右独立アーム、固定支点、アームと一体で動くプレート、上胸部方向の弧 |

模型の下に「狙う部位 / 意識する動き / 注意点 / コツ・練習」の４切替があります。胸の狙いの模式図、補助筋、短縮・伸張の説明、３つの間違いと直し方、練習・重量の扱いを日英で収録しています。上部・下部は強調部位であり、その場所だけを分離する説明にはしません。

## 動く人体と器具

既存の筋肉のある人体、握り、着色・収縮、三方向、四分の一速の片道再生と終点停止、手動姿勢、詳細操作、本格モードを使用します。追加の再生タイマー・外部モデルのダウンロード・依存ライブラリはありません。ガイドは全２６種目（既存２４＋胸ディップス・インクラインハンマー）。

ディップスの準備段階は上の支持姿勢、動作段階では下から押し上げる局面へ。ハンマーの模型はプレート式独立アームの教育模型であり、メーカーの正確な寸法を再現したCADではありません。実機の初期抵抗・調整方法を優先します。

既存の dumbbell-heavy / chest-press / pec-fly の識別子を維持し、カールやリアデルトと混ざった胸の説明を分離。過去の記録・保存キーを変更せず、データ移行は不要です。ガイド追加によってジムがその器具を保有すると推定しません。

## 重量と練習

性別だけで一律の開始重量を指定せず、軽い設定で余裕を残して制御できる負荷を案内します。初期の記録重量は未入力（胸ディップスのみ追加重量０）。種目変更時も前の重い記録重量を引き継ぎません。

ダンベルは片手分、ハンマーは片側プレート合計、チェストプレス・ペックフライは実機の選択重量、胸ディップスは追加重量を入力します。自重のみは０。補助重量を追加重量として入力しないよう、補助付きディップスを別種目として案内。プレートなしでもアームには抵抗があること、痛みのない可動範囲、補助・スタッフによる調整も説明します。

## 検証する接点・姿勢

全５種目を４１段階で検証し、腕・脚の長さ、両手と実グリップの一致、立体表示と平面代替表示の座標一致を確認します。ダンベルは胸の上で前腕が垂直になり、背もたれは頭まで支える長さにしています。ハンマーの開始姿勢は肘が肩より下に来るよう修正。支点とアーム・プレートの距離は動作中も一定です。

同じ種目を選び直したときは入力済み重量を保持し、別の種目へ変更すると記録重量を空欄（胸ディップスは追加重量０）に戻します。日英両モードで確認します。
