# TASK-049: チェストプレスの座面高と胸の狙い

2026-11-16。ユーザー指定の「椅子の高さによって効かせる胸の部位が変わることも加えて」に対応。TASK-048は2594776で受入済み。今回の追加解説のみを実施する。

## 追加内容

チェストプレスの動く模型の直下に「座面の高さで胸の狙いはどう変わる？」という折りたたみ解説を追加。初心者/本格のどちらでも利用できる。基本の高さから、少し低め/少し高めの3段階を比較できる。

| 設定 | 胸に対するグリップの位置 | 説明する負荷の変化 |
| --- | --- | --- |
| 基本の高さ | 胸中央付近 | 初心者の基本。胸全体で押し、肘は肩より少し低く保つ |
| 少し低め | 上部寄り | 胸上部や肩前面の関与が増える場合がある |
| 少し高め | 中〜下部寄り | その周辺への負荷の配分が変わる場合がある |

固定したグリップの青い点線に対して座面・体幹・肩の位置が上下する比較図で、座面とグリップの相対関係を示す。胸の着色で部位の目安も示す。

「座面だけで胸上部/下部を分離できる」と断定せず、機種の軌道・背もたれ角度・体格にも依存すると記載。肘が肩より高くなるほど下げないこと、足が浮くほど上げないこと、背中/臀部/足裏の支持、座面ロック、軽い設定での確認を説明する。既存の座面セットアップ本文にも同じ原則を反映した。

比較図は説明用であり、実際の負荷量を算出しない。上の3D模型は基本の高さの見本であることを明示。比較の選択は3D模型の座面・骨格・筋肉着色・軌道・再生状態を変更しない。新規アニメーション、時計、ストレージ、依存追加なし。

## 追補：胸8種目の座面高・インクライン角度（TASK-049継続）

ユーザーの追加指定により同じレビュー待ちタスクを拡張。今回の追補を受入済みとは扱わない。

| 種目 | 追加した設定の解説 |
| --- | --- |
| チェストプレス | 既存の座面3段階比較と基本位置を維持 |
| ペックフライ | 座面高で腕の位置と負荷配分が変わり得ること、肩と器具の支点合わせを優先すること |
| インクラインハンマープレス | 座面高と固定傾斜を区別。上胸部にグリップを合わせ、固定式の背もたれを勝手に変更しない |
| インクラインダンベルプレス | 台の高さは足の安定、背もたれ角度は胸/肩の関与に関係することを区別 |
| スミス式インクラインベンチプレス | 角度に加え、レールに合わせたベンチ前後位置・停止点・セーフティの再設定 |
| 通常ベンチプレス | 台を床と平行に維持。台高は支持のためで、胸部位の切替ではない |
| ケーブルクロスオーバー | 椅子ではなく滑車高と閉じる方向による関与の違い |
| ディップス | 椅子なし。支持高は乗り降りと足の安全、胸/三頭筋の関与は姿勢や肘の動きに関係 |

インクライン2種には、水平・15〜30度・45度・60度の比較を追加。図の実角度は0/30/45/60度で、15〜30度の選択肢は30度を例示していると明記した。背もたれと体幹の方向、胸/肩前面の部位を比較できる。

緩い傾斜は胸上部を意識する目安で、高くなると肩前面の関与が増えやすいと説明。「角度が高いほど胸上部に強く効く」「座面や角度だけで部位を完全分離する」とは断定しない。体格、握り、肘、軌道にも依存すると記載。

比較は説明図であり、3D模型の姿勢・角度・軌道・筋活動量を切り替える機能ではない。通常ベンチの水平・実スミスレール機構・人体/握り・動作を維持。角度の選択は解説の開閉・言語/モード切替では保持し、種目変更で基本の30度比較へ戻す。モデル本体はその種目の基本設定の見本のまま。

### 追加の確認手順

1. 胸8種目を順に選び、各種目に合う折りたたみ設定説明が出ることを確認。
2. インクラインダンベル/スミス式で比較を開く。初期が15〜30度、図は30度の例となっていることを確認。
3. 水平/15〜30/45/60度を切り替え、背もたれ角度と胸/肩の説明が同期することを確認。
4. 角度比較を閉じて再度開き、選択が残ることを確認。初心者→本格切替でも保持し、別種目へ移ると新しい説明を閉じた初期状態で表示することを確認。
5. スミス式の角度変更時の前後位置/セーフティ、ペックフライの支点合わせ、ハンマーの固定式背もたれ、通常ベンチの水平維持という違いをレビュー。
6. 実プレビューの日英・320/390幅で確認。非胸種目へ移ると設定説明が消えることを確認。
