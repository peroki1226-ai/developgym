# 模型を操作して正しい動き・効かせ方を学ぶ（ユーザー指定 / TASK-036）

## 変わった使い方

探索 →「胸の５種目を模型で学ぶ」→ 種目を選択 → **「この模型の正しい動きを見る」**。

準備の静止姿勢から、その場で押す・閉じる動作と戻しを１往復再生します。胸ディップスは上の支持姿勢から下ろし、押し上げて元に戻ります。終了時は止まります。既存の筋肉付き人体・器具形状・接点・５種目の解説を使用します。

- **停止・再開**：途中で止めて、同じ位置から再開。再生ボタンで毎回最初へ戻す動きにはしません。
- **手動バー**：指でタップ／ドラッグし、正しい軌道に沿って模型を進めたり戻したりできます。人体・器具・筋肉・説明は同じ再生位置に追従します。
- **少し戻す／進める**：タッチで細かく確認。画面読み上げの増減操作にも対応。Webプレビューでは矢印キー・先頭／末尾キーでも調整できます。
- **速さ**：通常・ゆっくり・もっとゆっくり。途中で変更しても姿勢は飛びません。
- **三方向と拡大**：初心者画面のままで前／横／後ろを選び、胸の収縮を拡大して確認できます。
- **既存の部分練習**：「動かすだけ」「戻すだけ」の四分の一速再生や手動姿勢、詳細操作も引き続き使用できます。

## 動きをどう伝えるか

動作中の模型に青い軌道・方向矢印を重ねます。ダンベル／マシンは手の移動、ディップスは固定した棒に対する体の上下を示します。戻す局面では矢印も反転します。部材・握りの位置を矢印の都合で変えません。

胸の着色と筋腹の変形に加え、模型直下に同じ進行位置で変わる短縮・伸張の模式図を表示します。「胸が縮みながら力を出す」「戻す時は胸が伸びながらブレーキ」の違いと、種目固有の短いコツが連動します。これは筋長や筋力の実測表示ではありません。モデル再生を運動記録として自動保存することもありません。

## 技術的な確認点

再生・ドラッグ・筋肉・呼吸・矢印は既存の単一の再生フックを使います。再生時計や外部動画・モデルのダウンロードを増やしません。１往復再生の終点、停止位置の保持、手動操作からの再開、画面離脱／バックグラウンド／アンマウント時の停止を確認します。

「動きを減らす」が有効なときは自動再生を抑え、バー・ボタンでの姿勢確認を使用します。種目の変更時は再生を止め、日英切替時は姿勢を保持して説明を切り替えます。

## Antigravityでの確認

main同期後、旧プレビューを停止して再生成してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`http://localhost:3000/app-preview/?lang=ja` / `?lang=en`。旧 index.html は対象外です。

1. 胸５種目それぞれで最初に見える「正しい動きを見る」を押す。
2. 模型が実際に動き、青い矢印・赤茶色の胸・短縮と伸張の説明が同じ局面を示すか。
3. 停止→再開、バーのドラッグ、少し戻す／進める、速度変更、三方向・拡大を試す。
4. ディップスは上から下ろして押すこと、他４種は押す／閉じる→戻すこと、１往復で止まることを確認。
5. 既存の解説と記録欄が使えるか。実iPhoneの性能・見やすさは別途受入が必要です。

今回ユーザーが求めた操作改善だけを対象とし、他タスクやTestFlight/EAS配布へは進めません。
