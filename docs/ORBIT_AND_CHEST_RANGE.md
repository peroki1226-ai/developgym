# ディップス・ペックフライの可動域と自由視点（ユーザー指定 / TASK-041）

## 指定２種の動作

- **胸ディップス**：固定グリップと上端の姿勢は保ち、下端の骨盤を模型内で３単位下へ。上下の移動幅は８．８→１１．８単位（約３４％増）です。手を棒に固定して、胸が伸びた位置から押し上げる様子を大きく見せます。腕の骨長・足を後ろへ浮かせる姿勢・器具の固定を維持します。これは個人に必要な深さを指定する数値ではありません。
- **ペックフライ**：開始角度を５８→９５度にして、手が肩の横から少し後ろへ開く位置へ。閉じた位置は従来通り、半径２８．５単位と肘の曲がりは固定です。上部支点・可動アーム・ハンガー・握り・カムと連動するウェイトも同じ開始角を参照し、開始時にウェイトが地面の下へ沈まないようにします。
- 日英の開始姿勢・座席設定・動作の短い解説を新しい模型に合わせました。肩を前へ落としたり、痛みのある深さまで無理に動かしたりする案内にはしません。

## 拡大と四方八方の確認

- 初期の立体表示を**１１５％**にし、模型の表示枠も３５０→４００に拡大。ボタンまたは回転モード中の二本指で**１００〜２５０％**に調整できます。拡大中は一部を画面外へ出して細部を見られます。
- 全２８種目に**前・左・後ろ・右・上・下**の６方向を追加。従来はベンチ系だけだった上方視点も全種目から選べます。
- **「指で自由に回す」**を押すと、模型の上を一本指で動かして周囲３６０度・上下へ連続回転。二本指で開く/閉じると拡大縮小します。上下角度は極を避けた範囲で止め、画面が反転しないようにしています。
- 左右上下のボタン、キーボードの矢印キー、読み上げの増減操作でも回せます。回転は自動で続かず、指を離した位置で止まります。
- **「回転を固定する」**で縦スクロールへ復帰。**「全体を収める」**は現在の方向のまま全身・器具を１００％で収め、**「視点をリセット」**は初期の方向/１１５％/回転固定へ戻します。どちらも種目の再生位置・記録入力は保ちます。
- 平面表示にフォールバックした場合は自由視点を隠し、回転モードも解除します。

自由視点のための再生時計・慣性ループ・依存ライブラリ・通信モデルは追加していません。姿勢が停止中なら、視点や倍率を変えても人体のスキニングと筋繊維バッファを再計算せず再利用します。種目変更でカメラ状態を初期化し、保存済みの運動・食事・検索データは変更しません。筋肉の着色と短縮区間は引き続き教育用の模式表示です。

## Antigravityでの確認

main同期後、古いプレビューを停止して以下を実行してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja` と `?lang=en` を使用。凍結中の index.html は対象外です。

1. 胸コース→ディップス→伸びた姿勢/縮んだ姿勢→横から。固定した手に対して体が下がり、胸が伸びる位置から押し戻すか確認。
2. ペックフライ→伸びた姿勢→横から。手が肩の横より少し後ろにあり、閉じる際も軽い肘の曲がりが保たれるか確認。
3. ６方向の切替→指で自由に回す→一本指の回転・二本指の拡大。回転中にページが動かず、固定するとスクロールに戻るか確認。
4. 姿勢を止めて、カメラを回す/拡大/全体を収める/リセット。姿勢と入力は変わらず、通常/半速/四分の一速・停止/再開・１往復終了も使えるか確認。
5. 他部位の種目でも６方向・拡大・自由回転を確認。日英の表示とスマホ幅の折返しも確認。

実iPhoneの見た目・性能の受入は別途です。今回のユーザー指定範囲のみを実施し、新規EAS署名ビルド・TestFlight提出/配布は行いません。
