# GymFinder 白青・旅行先ジム探索の画面刷新

2026-11-02、日本時間。ユーザーが参考画像の「デザインと機能を採用」を選び、「こんな感じで作りたい」と指示。今回の白青デザインを優先し、従来のモノクロ方針を更新する。

## 実装した構成

| 参考画面 | 実装・操作 |
|---|---|
| ホーム | 旅行写真ヒーロー、検索、地域・重量・メニュー条件、青い検索ボタン |
| メニュー入力 | 部位・種目名で絞り込み、選択/解除、端末自動保存、検索結果へ反映 |
| 検索結果 | 既存の適合率計算、内観イメージ、詳細・お気に入り・比較へ遷移 |
| 地図 | 地図タイル、ズーム、ピン選択、地域/検索条件と店舗一覧の連動。通信失敗時は一覧を維持 |
| 詳細 | 適合率、設備、実行可能/不足種目、料金/時間の確認状況、端末内レビュー/写真投稿 |
| 器具・メーカー検索 | 日英の器具・メーカー名で検索し、保有するサンプルジムを逆引き |
| おすすめ | 既存の条件計算で上位3件を提示。実AIと区別して説明 |
| 比較 | 2店舗まで選択し、適合率・器具数・ダンベル重量等を並べて確認 |
| ルート | 選択した店舗名とエリアをGoogle Mapsへ渡し、外部地図で経路を確認 |
| マイページ | 記録数・お気に入り・選択メニュー、既存の履歴/投稿/言語設定 |

下部はホーム・マップ・メニュー・お気に入り・マイページ。トレーニングフォーム、家トレ、食事/体重記録はメニュー・マイページ等の記録ツールから利用する。既存の保存schema v4と保存キーは維持し、検索設定のみ別のバージョン付きキーへ保存する。読み込みに失敗した検索設定は上書きしない。

白/淡い青の背景、青い主操作、濃紺の文字、緑の適合率を使用。48ポイント以上の操作領域とSafe Areaを維持し、アプリアイコン・スプラッシュ・フォーム図解・食事グラフも配色を揃える。日本語/英語の純粋言語分離を維持し、利用者入力は原文を保持する。

## データと未接続の機能

- 店舗は元の5店舗の検証用データ。地図の座標は近似サンプルで、実際の営業店舗や設備情報を確認済みとは扱わない。
- 料金・営業時間・他ユーザー評価・経路の所要時間を捏造しない。レビュー評価はこの端末の実投稿がある場合だけ算出する。
- 写真は今回生成した旅行背景/汎用ジムのイメージ。実店舗の撮影写真と混同しないよう内観に「イメージ」を表示する。
- おすすめは条件計算。実AI・実店舗データAPIとの接続は未実装。TASK-014/015の別環境の未共有ソースを統合したとは扱わない。
- 地図を開くとOpenStreetMapへタイルを要求する。位置情報の許可/現在地取得は行わない。提供元の著作権表示・リンクを表示し、通信動作をポリシードラフトへ追記する。ライブの地図提供や精度は実機で確認が必要。

## 検証と配布

既存71件に10件を追加し15 suites/81 tests成功。型チェック、release:check、iOS/Android HermesバンドルとExpo Webの検証用出力が成功。新タブ・メニュー復元・詳細/経路・比較上限・メーカー検索・地図失敗時の操作継続・両言語の全新画面・破損保護/再試行を確認する。

Expo Web出力は同じmobile/の画面をブラウザーで確認する開発用成果物で、ルートindex.htmlのWebプロトタイプやiPhoneに配布するアプリとは区別する。通常の配布は引き続き署名付きRelease/TestFlight。既存EAS projectId・認証・未共有差分の同期待ちのため、新しい署名ビルド/実機インストールは今回行っていない。
