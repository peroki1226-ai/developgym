# 日本語モードと英語モード（2026-11-09、日本時間）

## アプリで選ぶ

画面上部の言語ボタン、またはマイページの「表示言語」から選ぶ。

| 選択 | 日本語モードでの表示 | 英語モードでの表示 |
| --- | --- | --- |
| 日本語を使う | 日本語モード | Japanese mode |
| 英語を使う | 英語モード | English mode |

選択中のモードにチェックと色を付け、「現在：日本語モード」または「Current: English mode」を表示する。ヘッダーとマイページは同じ言語状態を使い、画面・説明・器具名・筋肉名・操作案内がまとめて切り替わる。端末への保存中/保存済み/失敗も区別する。

日本語と英語でアプリを複製したり、保存キーを分けたりしない。トレーニング記録、体重、食事、器具、お気に入りは同じデータを保つ。利用者が入力した投稿などの原文は保全する。任意の文章を機械翻訳するサービスは追加していない。

## プレビューの二つの入口

Antigravity側で最新mainに同期し、旧サーバーを停止してから実行する。

```sh
cd mobile
npm run preview:app
```

- 日本語モード：`http://localhost:3000/app-preview/?lang=ja`
- 英語モード：`http://localhost:3000/app-preview/?lang=en`

起動ログにも両方の入口を出力する。上記は起動したPC内のアドレスで、iPhone向け公開リンクではない。

明示したモードは以前の保存言語より優先する。例えば日本語で保存していても、英語用の入口から開くと英語になる。通常の起動では保存言語を復元する。切替時にURLの`lang`も更新し、英語へ切り替えた後に再読み込みで日本語へ戻らないようにする。`revision`など他のパラメーターやハッシュは維持する。

旧入口`/gym-app-preview.html?lang=en`、`/index.html?lang=en`、`/?lang=en`からも英語モードへ進める。`ja`と`en`以外、または複数の`lang`指定は採用せず、保存言語へ戻す。ソース変更で古いプレビューが拒否される場合にも、指定モードで更新案内を出す。

URLによるモード指定はWebプレビュー用。iOS/Androidでは共通の画面内設定と端末保存を使う。OSのシステム画面の言語設定は別。TestFlight/EASの新規ジョブや実機配布は実行しない。

## 検証

- 二つのモードの排他選択、ヘッダーとの連動、再起動復元。
- 明示モードと保存済み言語が異なる起動、読込失敗後の新しい選択の優先。
- URL切替、別パラメーター/ハッシュの維持、不正モードの無視。
- 実際に作成したトレーニング記録が、逆のモードの入口から開いても変わらないこと。
- Expo Webで126状態。日英それぞれの5タブ、家トレ/食事/トレーニング、全24種目×初心者/本格、筋肉/動作詳細、入口/再読込み/更新案内。提供文言の他言語混入とブラウザー実行エラーなし。

証跡は`gymfinder-language-modes`の画面・比較画像・検証JSON。実描画はChromium/SwiftShaderによるブラウザー検証であり、iPhoneやAntigravity別環境の実機受入とは区別する。モデルの造形・動きの受入判定はTASK-029/031で継続する。
