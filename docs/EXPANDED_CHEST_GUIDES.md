# 胸の種目追加と初心者の動くフォーム（ユーザー指定 / TASK-038）

> 現在のインクラインはTASK-042で写真型スミスへ変更済みです。最新仕様は[スミス式の確認手順](SMITH_INCLINE_PHOTO.md)を参照してください。以下はTASK-038当時の記録です。

指定されたインクラインベンチプレス、ケーブルクロスオーバー、インクラインハンマープレス、ベンチプレスを、通常メニューと初心者の動くフォームから確認できるようにしました。

## 種目の整理

| 表示名 | フォームの識別子 | 今回の対応 |
| --- | --- | --- |
| インクラインベンチプレス | incline-bench-press | フリーのバーベルと約３０度のベンチを新設。スミスマシンとは別種目 |
| ケーブルクロスオーバー | cable-machine | 既存の識別子を維持し、胸の初心者コースへ統合。立位・前後の足・肘角度を保つ開閉をモデル化 |
| インクラインハンマープレス | incline-hammer-press | 既存ガイドをそのまま使用。重複を作らず通常メニューにも追加 |
| ベンチプレス | barbell-bench-press | 水平ベンチとフリーのバーを新設。家トレのダンベルベンチの識別子とは分離 |

胸の初心者コースは５→８種目、全フォームガイドは２６→２８種目。ケーブルとハンマーは再利用し、新しいフォーム識別子は２種類だけです。選択ボタンの「５種目」という固定表示を一般的な「胸の種目」へ変更しました。

## 入口

探索の「胸の種目を模型で学ぶ」→「胸の種目から選ぶ」。またはメニュー一覧から「○○の動くフォームを見る」で直接開けます。選択したメニューや検索入力は、戻っても保持します。器具の必要条件と種目の説明を分離し、ベンチプレスの説明はラックのスクワットではなく、ベンチプレスの模型を開きます。

## 模型と学習

- フリーのバー２種は、左右の手・バー・プレートが一体で動き、ラックとセーフティ、足は固定。レールはありません。手の位置より外側にラック、さらにその外側にプレートが来る構成です。
- ベンチは水平と約３０度を分け、背もたれ・フレーム・支えを描画。初心者の動作ステップは正面寄りから始め、手とバーがラックに隠れにくい視点にします。
- ケーブルは軽い前傾、前後に開いた足、曲がりを保つ肘を使います。左右の手は胸の前へ閉じ、初心者に無理な交差を求めません。ケーブルは手を貫かず、ハンドルの取付部へつなぎます。
- 既存の自然な人体、筋肉の着色・短縮/伸張、青い軌道、１往復再生、停止/続きから再開、低速、手動バー、三方向・拡大、記録保存をそのまま使用。平面表示も同じ立体座標を使います。

３種の追加教材には狙う部位、協同筋、準備、手足、動作の各局面、意識、３つの間違いと直し方、練習と記録方法を日英で収録。フリーのバーはセーフティ・補助者・軽量バーからの練習を案内し、バー＋左右プレートの合計を記録します。ケーブルは片側の選択重量です。模型のプレート枚数を開始重量の指定にはしません。

## 検索データと保存

通常メニューは既存のベンチ/ケーブルを維持し、インクラインベンチとハンマーの２件を追加（１６→１８）。インクライン用ベンチ一式と独立アームの設備タグも追加しましたが、デモ店舗の保有登録は推測で増やしていません。一般的なチェストプレスがあるだけでハンマーが使えるとは判定しません。

既存の種目ID・保存キー・検索の計算式は維持。旧メニュー選択の復元、追加メニューの保存、フォームからの記録を確認します。以前の８種目選択で算出する９２％の重み付き判定も維持します。

## Antigravityでの確認

main同期後、古いプレビューを止めて再生成してください。

```bash
cd mobile
npm run preview:app -- --port 3000
```

`/app-preview/?lang=ja` と `?lang=en`。旧 index.html は対象外です。

1. 指定４種目が、通常メニューと胸コースの両方から正しい模型を開くか。
2. 水平／傾斜のベンチ、フリーのバーとラック、両手の握り、ケーブルの肘・足を確認。
3. １往復再生、停止/再開、手動ドラッグ、低速、三方向と拡大を確認。
4. 記録の重量解釈と保存、元の検索への復帰、日英表示を確認。

実iPhoneの見た目・速度の受入は別途です。今回依頼された種目追加のみを対象とし、TestFlight/EASの新規ビルド・配布へは進めません。
