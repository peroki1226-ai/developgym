# 自然につながる関節と器具の奥行き（TASK-028）

2026-11-07（日本時間）。全24種の腕・脚・関節拡大を、継ぎ目を持たない人体の輪郭へ更新し、器具の前面/側面/奥側を描き分けました。

## 人体・関節

- 上腕/前腕、太もも/下腿を、関節をまたぐ一続きの輪郭で描きます。肘・膝の中心に円柱の端面や白い穴を置きません。
- 上腕とふくらはぎの厚みを変え、関節の内側には折れ目、膝頭には柔らかな明暗を加えています。深く曲げた内側は輪郭を切り詰め、線が重なって小さな輪になることを防いでいます。
- 肩の付け根は柔らかい明暗で胴体につなぎ、首と僧帽部を胴体の上端と連続させています。手は指を曲げた形と親指を描き、握りの中心は元の座標のままです。
- 関節に重なっていた大きな案内リングを、小さな点と引き出し線へ変更。番号①/②は維持しました。
- 関節拡大にも同じ人体の輪郭を使用し、肘/膝/股関節/背中の動きを厚みのある形で確認できます。元の骨の角度、開始姿勢の薄線、角度の案内は維持しています。

## 器具

- フレーム/パッドには前面とは別に側面と端面を追加。押し出し方向に応じ、前面に隠れない面を選んで描画します。
- 座面とウエイト塔に上面/側面、プレートに厚み、回転軸に奥側の縁を追加しました。
- ラック/補助懸垂には奥側の支柱と連結部、レッグプレス/ハックスクワットには奥側のレールを追加し、箱やレールの前後関係を示します。
- 握り部はゴム状の凹凸と向きを加え、手指がその中心を包む表示にしています。

## 実装と保全

`domain/articulatedSurface.ts`は既存の肩・肘・手、股関節・膝・足首を中心とする滑らかな輪郭と折れ目を算出します。骨の長さや関節/接点、IK計算は変更していません。`ArticulatedLimb.tsx`を本体と拡大図で共用し、種目ごとに独立した別動作を作らない設計です。

`domain/equipmentSurface.ts`は元の前面座標を保ったまま奥側の面を生成します。`ExerciseEquipment.tsx`のフレーム/パッド/塔と、奥側の支柱/握り部に適用しました。斜めの投影で厚みを表現するもので、自由に回転する三次元メッシュや個別メーカーを精密に再現するモデルではありません。

筋肉の赤茶色表示と輪郭による切り抜き、筋繊維/筋節の短縮・伸長/姿勢保持、3速度、41段階コマ送り、再開、背景/非表示/動きを減らす対応、記録と入力保持、純粋日英を維持。新しい再生タイマー、画像ダウンロード、依存、権限、保存形式、EAS設定、旧Webの変更はありません。
